## 使用

先安装Git LFS，再克隆并执行`git lfs pull`，否则MAT和SLX可能只是指针文件。MATLAB需配置Simulink、电力系统相关工具箱和MPT3；正式训练使用项目自己的ReLU实现。不要为了看图重新训练。

```matlab
% MATLAB当前目录切到克隆所得根目录后：
cd('48_72_120_C220_16_8');
run_all_modes('plots');   % 查看已经保存的结果
% run_all_modes('closed'); % 明确需要时才重新运行九工况
% run_all_modes('train');  % 明确需要时才重新训练五份网络
```

各工况的`code`中按原流程保留`model_calculate → EMPC1 → train_sample → zhenghe → myguiyihua → run_closed_loop`。修改物理参数需重新辨识和核验，不是只改网络结构。切换工况使用组成模式网络，不另存四套切换网络。
