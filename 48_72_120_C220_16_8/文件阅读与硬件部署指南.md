# 220 µF工程：文件怎么用，以及以后怎样上硬件

本文以 `EMPC_LOOP/SU_SISO_VS48_Vo120/code` 为例。其他独立模式沿用同一流程，但必须使用各自的参数、模型、网络和开关映射。

## 1. 先记住整条链

电脑上的离线设计：

`parameters → model_calculate → EMPC1 → train_sample → zhenghe → myguiyihua → run_closed_loop`

对应的事情是：设参数 → 辨识电路 → 设计精确EMPC老师 → 向老师提问得到标签 → 整理训练集 → 训练网络学生 → 接入实际开关电路验证。

硬件每个控制周期做的事情：

`ADC采样 → 换算成安培/伏特 → 输入归一化 → 网络前向计算 → 占空比限幅与模式映射 → 更新PWM`

硬件运行网络时，不必在线重新辨识、训练或求解二次规划。EMPC提供离线教师标签；网络近似它的控制规律，两者并非数学上完全相同。

## 2. 每个主要文件怎么用

先进入本工况的code目录：

```matlab
codeDir = 'D:\Project\NN_EMPC_TPC\48_72_120_C220_16_8\EMPC_LOOP\SU_SISO_VS48_Vo120\code';
cd(codeDir);
```

| 文件／运行命令 | 读什么，做什么 | 主要输出 | 需要掌握到什么程度 |
|---|---|---|---|
| `parameters` | 声明电压、L/C、负载、采样周期、约束、权重、网络结构和初始化 | 工作区中的cfg、initialization | 必须逐项理解，是日常参数入口 |
| `model_calculate` | 在电路工作点附近施加PRBS小扰动，读取电流、电压、占空比，辨识每种负载的离散模型 | models/identified_model.mat，辨识数据与图 | 理解输入输出、采样周期、A/B/f和留出误差 |
| `EMPC1` | 读取辨识模型，设置预测、约束和代价，计算显式控制律 | models/EMPC_48_72_120.mat；generated中的控制器 | 理解预测模型、权重、约束和控制律 |
| `train_sample` | 查询EMPC，把许多状态对应的占空比存成标签，并产生独立非网格测试数据 | data/shu_all.mat、data/offgrid_holdout.mat等 | 理解标签是谁给的，以及采样覆盖范围 |
| `zhenghe` | 合并各负载样本，整理为统一矩阵 | data/changeR1.mat | 理解每列含义，避免列顺序错误 |
| `myguiyihua` | 归一化、划分训练/验证/测试集，训练两隐藏层ReLU网络 | models/net_48_72_120.mat；网络测试结果 | 必须理解输入缩放、权重、偏置和前向公式 |
| `report = run_closed_loop` | 用保存网络建立并运行实际开关电路，施加负载变化，记录物理波形和验收指标 | circuit电路、results轨迹/报告/图 | 理解这是电路闭环验证，并读懂每个平台与变化事件 |
| `show_results` | 只读已保存结果 | 显示闭环总览、变化处电压放大 | 平时查看结果用这个，不需要重新训练 |
| `show_all_results` | 只读已保存的详细结果 | 显示本工况更多分析图 | 深入检查时使用 |
| `organize_circuit` | 整理本工况保存的SLX并打开闭环模型 | 控制与日志分层的电路图 | 学习读电路时使用，不训练、不重新仿真 |
| `run_all` | 顺序运行上面六个计算阶段与闭环验证 | 更新整套数据、控制器、网络和结果 | 完整重做时使用，会耗时并更新产物 |

这些入口多数是函数，直接输入文件名运行即可。不要把每个函数里的代码逐段粘到命令窗口。`parameters.m`是参数脚本。

已有结果不需要为了学习而重跑训练。先看参数、保存的数据、公式和图。

## 4. 参数具体怎样解释

下面是48→120 V工况的当前值，不能直接套到其他工况：

| 参数 | 当前值 | 意义 |
|---|---:|---|
| Vs、Vb、Vref | 48、72、120 V | 电源、电池和受控电压参考；本SISO模式并不表示三个端口都同时传能 |
| Rloads | 48、96 Ω | 120 V时分别为300、150 W；实际功率随实际电压变化 |
| L、Co | 110 µH、220 µF | 功率级物理参数，必须与实物和辨识条件一致 |
| fsw | 100 kHz | PWM周期10 µs |
| Ts | 10 µs | 控制器更新周期；不是求解器积分小步长 |
| N | 30 | 向前预测30步，即300 µs；网络运行时不再在线做30步优化 |
| Qx、Qy | 0.03、3000 | 电流状态与电压跟踪的代价权重；改变它们会改变控制规律 |
| currentMax | 18 A | 控制器设计约束，不等于采集板量程，也不等于硬件过流保护阈值 |
| dutyMax | 0.94 | 当前配置的占空比上限；不是额定工作点占空比 |
| hiddenSizes | 16、8 | 本轻量化副本的两隐藏层分别有16、8个神经元 |
| nnVoltageDomain | 115～125 V | 当前局部网络的电压设计范围；不能据此宣称0 V冷启动已由网络覆盖 |
| events | 60、70 ms | 仿真中安排变化的时刻，不是实际硬件必须采用的工作时序 |
| initialization | 单独声明 | 启动、预运行与网络接管设置；与正常稳态网络控制分开理解 |

微小负电压/电流下界是模型和数值设计的一部分，不表示要求实物产生负电压。A、B的负系数也不能为了图好看直接改成正数。

## 5. 三种数学对象不能混淆

### 电路辨识模型：用来预测

状态向量是两个量：`x = [iL; V]`。当前辨识模型为：

`x(k+1) = A*x(k) + B*u(k) + f`

A描述状态对下一时刻的影响，B描述占空比的影响，f是工作点对应的仿射常数。**当前模型必须保留f，不能只复制A、B。** 这也与早先只用固定占空比启动数据回归的版本有区别。

它是围绕已采集工况的模型。一步误差小，只能说明相应数据上的一步预测好，还要检查电路闭环、负载变化和模式切换。

### EMPC控制律：给出精确教师标签

EMPC用上述模型，在约束内权衡电压误差和电流代价。离线求出不同状态区域中的控制公式，运行时按状态选区域并计算占空比。

generated中带`_scaled`的是内部缩放坐标版本；对应的实际单位包装函数负责换算。通过包装函数查询时不要再自行重复缩放。分区图的颜色代表不同控制区域或占空比，并非电路仿真波形。

### 神经网络：近似教师控制律

网络有四个输入，而辨识状态只有两个。这不矛盾：

`s = [iL; 受控电压; 负载电流特征; 参考电压]`

在实际闭环中第三项使用对应测量信号；不要擅自换成恒定2.5 A。标签生成过程中会由负载关系和增强方法构造该特征。不同模式必须跟随各自电路的信号定义与方向。

四个输入不代表已经覆盖任意参考电压。当前参考是各工况的固定72或120 V，泛化范围要由数据和验证说明。

标量占空比模式的训练矩阵为5列：`[iL, V, 电流特征, Vref, d]`；DISO为6列，最后两列是两个独立控制输出。

当前网络的前向计算：

```matlab
z  = net.inputGain .* s + net.inputShift;
h1 = max(0, net.W1*z  + net.b1);
h2 = max(0, net.W2*h1 + net.b2);
u_raw = net.W3*h2 + net.b3;
```

W1为16×4，W2为8×16，W3为nu×8；nu为该工况独立输出数。隐藏层ReLU把负数置零，输出层是线性的，之后还要执行配置规定的占空比限幅及PWM映射。

`models/net_48_72_120.mat`保存net及training等记录。硬件所需核心是W1/b1/W2/b2/W3/b3、inputGain/inputShift，以及外部限幅、信号和时序规则，而不是训练样本矩阵。

## 6. 不重训也能亲手验证一次网络计算

在48→120 V工况code目录运行下面内容。它只读取已有文件，取真实闭环最后一个记录点，手算一次网络，核对已保存的原始网络输出：

```matlab
P = load(fullfile(pwd,'models','net_48_72_120.mat'),'net');
T = load(fullfile(pwd,'results','NN_native_trajectory.mat'), ...
    'log','prediction');
net = P.net;
k = size(T.log,1);
s = T.log(k,2:5)';

z = net.inputGain .* s + net.inputShift;
h1 = max(0,net.W1*z + net.b1);
h2 = max(0,net.W2*h1 + net.b2);
u_raw = net.W3*h2 + net.b3;

disp('四个物理输入：[iL;V;电流特征;Vref]'); disp(s);
disp('手算的原始网络输出：'); disp(u_raw);
disp('保存的原始网络输出：'); disp(T.prediction(k,:)');
disp('两者最大绝对差：');
disp(max(abs(u_raw - T.prediction(k,:)')));
```

这段对应当前两隐藏层ReLU网络。不要把限幅后的PWM命令与限幅前网络输出混在一起比较。private里的函数是内部辅助函数，不要求你从命令窗口直接调用它。

## 7. 哪些结果图需要会讲

| 图 | 需要回答的问题 |
|---|---|
| 辨识图 | 预测与实测差多少？是否用了独立留出数据？ |
| EMPC控制律 | 哪种状态要求多大占空比？约束边界在哪里？ |
| 网络拟合 | 是否逼近教师？随机测试、独立非网格测试、控制区误差分别多少？ |
| 闭环总览 | 受控电压是否稳住？电流、负载与占空比怎样变化？ |
| 事件放大 | 负载或模式变化后偏差多大，按什么误差带判定恢复？ |
| 稳态纹波 | 原始开关波形的纹波有多大？不能仅看周期均值 |
| 轨迹教师对照 | 在电路实际走过的同一批状态上，网络与EMPC输出差多少？ |

轨迹教师对照是同一轨迹上的查询比较，不是已经做了两套独立闭环的性能对比。训练MSE、占空比误差和电压稳态误差是三种不同指标。

当前五种网络都未达到原设1e-8训练目标；已通过的是所声明仿真条件下的稳态验证，不能把它写成训练目标通过。

## 8. 其他模式与切换怎么理解

五个独立模式各自有同样的主文件流程。48→72 V模式的受控电压是电池端72 V；其他模式必须看parameters和电路接线确认受控量。DISO有两个网络输出，输出头和PWM通道必须成对匹配。

四个切换目录复用对应独立模式的网络，运行切换电路时保留电感、电容的连续物理状态，再切换控制与开关映射；不是另外训练了四个切换网络。因此切换目录中有些数据/模型目录为空是正常的。

当前切换由仿真事件安排。硬件还需要明确“何时允许切换、先后次序、互锁、异常退出”等状态机规则。仿真Step块不等于硬件自动模式管理已经完成。

## 10. 将来部署到硬件，具体搬什么

需要实现并核对：

1. **采样换算**：ADC码先换算为电压，再按采集电路增益、偏置和校准系数换算为安培/伏特。确认正负方向、通道顺序和有效带宽。
2. **相同输入处理**：物理量按训练时完全相同的顺序进入网络，使用保存的inputGain和inputShift。不能把ADC整数直接送进当前网络。
3. **相同网络前向计算**：导出权重、偏置，实现两层ReLU和线性输出。`.mat`是数据文件，FPGA不能直接执行它。
4. **输出与开关映射**：限幅后的控制量送到对应PWM；DISO的两个输出、固定开关和跨段关系必须与原模式一致，不能把每个开关占空比都设成同一个数。
5. **采样与更新时序**：100 kHz下一个周期为10 µs。测量、传输、计算、PWM寄存器更新时间必须明确；实际延迟要带回仿真验证。
6. **初始化、模式管理和保护**：启动到网络接管、模式切换、过流过压关闭、驱动互锁与死区等需要硬件实现。按老师要求不以启动峰值作本轮稳态验收，仍不等于实物可以省略启动与保护。

当前Simulink网络是浮点功能参考，尚未生成并验证FPGA工程、定点位宽、HDL、资源占用或时序。现有仿真采样保持也不能替代所有真实ADC、传输和计算延迟。

定点实现需要先统计输入、各层中间值与累加器范围，选择位宽、舍入和溢出规则；再用同一批测试向量逐层比较浮点与定点，最后加入量化和延迟重做闭环。不要先随意规定“16位一定够”。流程可参考MathWorks官方的[定点转换与类型选择](https://www.mathworks.com/help/hdlcoder/fixed-point-conversion-basics-and-type-specification.html)及[HDL生成、验证与综合](https://www.mathworks.com/help/hdlcoder/gs/generate-hdl-code-from-matlab-code-using-the-command-line-interface.html)；这不表示本工程已经具备对应许可证或可一键生成硬件。

## 11. 改了东西后从哪里重做

| 改动 | 应从哪里重新检查 |
|---|---|
| 只想读结果 | show_results，无需重算 |
| 只改图片样式 | 绘图，不重训 |
| L/C、电压、主要负载范围、控制周期变化 | 从辨识开始，重新设计、采样、训练并闭环验证 |
| 只改EMPC约束、权重、预测步长 | 从EMPC1开始；模型的适用范围也要确认 |
| 只改网络结构/训练超参数 | 从myguiyihua开始，再闭环验证 |
| ADC缩放、定点精度、计算延迟、PWM时序变化 | 数值对照和含实际接口的闭环验证；若改变物理范围/控制周期，再向前重做 |

不要仅改parameters就宣称已有.mat模型、网络和图已经对应新参数。尤其不要绕过数据缓存的物理参数一致性检查。

## 12. 推荐学习次序与掌握标准

第一轮只学48→120 V一个模式，按下面顺序：

1. 打开parameters，能解释48/96 Ω、220 µF、100 kHz、10 µs和30步分别是什么。
2. 用第6节取真实样本，亲手算出网络占空比，能说明四个输入单位及顺序。
3. 打开电路，沿着测量→四输入→采样保持→网络→限幅→PWM找一遍，认出独立控制量与实际门极不是一回事。
