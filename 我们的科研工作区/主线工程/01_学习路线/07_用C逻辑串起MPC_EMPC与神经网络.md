# 07：控制器怎么决定占空比

五个电路模式已经讲过，现在先用最熟悉的 **Vs→Vo：48V输入、200V输出** 进入控制算法。其他模式后面再套相同思路。

本课先讲清执行逻辑，不要求你先学优化工具箱，也不重跑前面已经验证的仿真。

## 1. 从你熟悉的控制循环开始

```c
// 概念流程，不是可烧录固件；省略采样同步、延迟和保护实现。
void control_tick(void) {
    float il = read_inductor_current();
    float vo = read_output_voltage();
    float duty = controller(il, vo);
    set_pwm_duty(duty);
}
```

你已经知道PWM如何让电感储能、放能。现在要解决的是：**controller()凭什么返回这个duty？**

先分清这些量：

| 量 | 意义 | 在这一案例中 |
|---|---|---|
| iL、Vo | 电路当前状态，随运行变化 | 控制器要读取的电流、电压 |
| d | 控制输入 | 要决定的占空比 |
| Vref | 目标 | 200V |
| Vs、L、Co、R | 电路模型参数 | 用来描述电路行为，R可随负载切换变化 |
| Ts | 更新或离散步长 | 必须按具体模型核对，不能把所有采样时间混为一谈 |

所以 `x=[iL;Vo]` 只是把两个变量装进一个数组；`u=d`就是一个控制量。

## 2. 为什么不能只用固定占空比

前面推导过稳态理想关系：

$$d=\frac{V_o}{V_s+V_o}=\frac{200}{248}\approx0.806$$

这个值告诉我们稳态数量级，却没有告诉我们启动时怎么到200V、负载突变时怎么恢复、怎样限制电流。

控制器要反复根据测量更新d，而不是一直输出0.806。决定d之前，先需要一个“假如我这样控制，电路下一步会怎样”的预测函数。

## 3. 电路预测模型：输入一个d，算下一步iL、Vo

Vs→Vo模式的理想平均方程是：

$$L\frac{di_L}{dt}=dV_s-(1-d)V_o$$
$$C_o\frac{dV_o}{dt}=(1-d)i_L-\frac{V_o}{R}$$

第一条：储能段电感电压是Vs，放能段是−Vo，按时间比例求平均。

第二条：只有放能段给输出送电流，平均送入输出的电流约为 `(1−d)iL`；减去负载电流 `Vo/R`，剩下的才是电容电流。

用最直观的一步欧拉近似，可写成：

```c
void predict_physics(float il, float vo, float d,
                     float Ts, float Vs, float L, float Co, float R,
                     float *il_next, float *vo_next) {
    float dil_dt = (d*Vs - (1.0f-d)*vo) / L;
    float dvo_dt = ((1.0f-d)*il - vo/R) / Co;
    *il_next = il + Ts*dil_dt;
    *vo_next = vo + Ts*dvo_dt;
}
```

两条导数都必须使用同一个时刻的il、vo，不能先更新il，再拿更新后的il算vo。

**上面用来理解物理关系；原EMPC脚本实际使用的是辨识得到的线性离散模型，并不是直接调用这段平均方程。**

原副本 `代码/EMPC1.m` 当前启用的系数为：

$$x_{k+1}=Ax_k+Bd_k$$
$$A=\begin{bmatrix}0.9960&-0.0021\\-0.0002&0.9996\end{bmatrix},\qquad B=\begin{bmatrix}0.7940\\0.1395\end{bmatrix}$$

翻译成C只剩两行：

```c
il_next =  0.9960f*il - 0.0021f*vo + 0.7940f*d;
vo_next = -0.0002f*il + 0.9996f*vo + 0.1395f*d;
```

A描述当前状态如何影响下一步，B描述占空比如何影响下一步。`C=[0 1]`表示从状态数组取第二项Vo作为受控输出。

这些系数来自项目现有脚本；它们与历史导出控制器是否完全同版本、对应什么数据和离散步长，下一课沿数据来源核对。现在不要把它们当成由L、Co直接代入就得到的常数。

## 4. MPC：预测未来几步，选一个合适的d

只看Vo低于200V就把d加大，可能把电感电流推得过高。MPC同时考虑“电压要接近目标”和“电流不能失控”。

一次更新的逻辑是：

1. 读取当前 `x=[iL;Vo]`。
2. 用预测模型计算未来N步的状态。
3. 寻找满足约束、综合代价较小的控制序列。
4. **只执行序列的第一个控制量。** 下一次重新测量、重新预测、重新选择。

```c
float mpc_control(float il, float vo) {
    // 这一步通常交给优化求解器，不是一个现成的C关键字。
    Sequence best = solve_prediction_problem(il, vo, Vref, N);
    return best.d[0];
}
```

预测20步不代表开环执行20步。就像你规划了未来20次动作，但执行一次后就根据新情况重新规划。

原 `EMPC1.m` 设置 `N=20`。这是20个模型离散步，不是20μs；物理预测时长是 `20×模型离散步长`。`Nsim=10000`则是该脚本的闭环模拟步数，不是预测步数。

### 怎么评价“好不好”

原脚本设 `Qy=3000`、`Qx=diag(3,0)`。理解其主要惩罚项可以写成：

$$J\sim\sum\left[3000(V_o-200)^2+3i_L^2\right]$$

电压偏离目标会被罚，电流过大也会被罚。上式用来说明权重含义，具体求和索引和控制分块由工具箱配置决定；脚本还将前5个控制量设为一个控制块。

脚本约束包含 `0≤d≤1`、`0≤iL≤92A`、`0≤Vo≤200V`。这些约束针对预测问题。预测模型误差、执行延迟和网络近似都会影响真实电路，不能据此宣称仿真或样机实际电流一定不超过92A。

权重是算法设计参数，通过验证调整；L、Co是电路参数；A、B是预测模型参数。三类参数的来源不同。

## 5. EMPC：把每次求解，变成找区域、代公式

如果在线解MPC太费时，可以离线把一片状态范围内的优化结果提前算好。

EMPC中的E是 **Explicit，显式**。在线输入仍是il、vo，输出仍是d；变化的是计算方式。

离线生成很多区域，每个区域配一条控制公式：

$$d=F_ri_L+G_rV_o+g_r$$

```c
float empc_control(float il, float vo) {
    int region = locate_feasible_region(il, vo);
    if (region < 0) return NAN;
    return F[region]*il + G[region]*vo + bias[region];
}
```

这是结构示意。原 `Bstep_controller10.m` 实际逐区域检查不等式；若命中多个区域，还比较目标值再选择，找不到区域则返回NaN。它不是简单按电压、电流四舍五入查表。

原脚本中的连接关系：

```matlab
ctrl  = MPCController(model, N);  % 定义MPC问题
ectrl = ctrl.toExplicit();       % 离线生成显式控制律
% 随后导出 Bstep_controller10.m
```

在相同模型、代价和约束下，EMPC目的是显式表示原MPC控制律；不需要在线再解一次完整MPC。

## 6. 神经网络：再学习“状态→占空比”这个函数

先用EMPC产生很多例子：

```text
输入：某个iL、某个Vo     标签：EMPC算出的d
输入：另一个iL、Vo      标签：EMPC算出的另一个d
……
```

训练神经网络，使它的输出接近这些标签。在线时只做固定权重运算：

```c
float neural_control(float il, float vo) {
    return nn40_duty(il, vo);  // 输入状态，直接返回占空比
}
```

网络不会在每次控制时重新训练，也不会在线先调用EMPC。它近似的是控制器，而不是自动重新推导电路。

本项目有两个很容易混淆的“学习”：

| 学什么 | 输入 | 输出 | 用途 |
|---|---|---|---|
| 辨识电路预测模型 | 当前iL、Vo、d | 下一步iL、Vo | 得到预测用的A、B |
| 拟合控制律 | 当前状态等特征 | EMPC给出的d | 在线快速算占空比 |

一个学“电路下一步怎么变”，另一个学“现在该怎么控制”。

## 7. 项目里两条链，分别在哪儿执行

**离线准备：**

```text
电路仿真数据 → 辨识预测模型 → 建立MPC → 生成EMPC
                                         ↓
                   扫描状态，查询EMPC得到占空比标签
                                         ↓
                           训练网络 → 保存权重/生成模块
```

**当前SISO模型在线闭环：**

```text
电路 → 测量iL、Vo → Delay → 已保存的神经网络 → PWM → S1、S2
  ↑__________________________________________________|
```

原模型网络模块名为 `shu150和shu300以及变载`。虽然外部接入4项输入，该已保存网络的预处理实际只保留iL、Vo；负载特征和参考电压两个恒定输入被删除。因此目前不能把这两个端口都说成网络有效使用的自适应信息。

已提取的网络结构为 `2 → 40 → 1`，独立MATLAB推理与原Simulink模块在1000个测试点的最大绝对差约 `5.09×10⁻¹³`。这验证了推理提取的一致性；从头重训得到同一网络，以及C编译和上板运行，还没有完成。

EMPC历史标签与网络输出也存在近似误差，所以原MPC的约束不会自动成为神经网络的硬保证。前面观测到的启动大电流，后面需要结合模型和控制链处理。

## 8. 你现在应该能这样讲

> 电路状态是电感电流和输出电压，控制量是占空比。先用电路数据得到预测模型，再建立带约束的MPC。EMPC把优化结果提前转成分区控制公式，随后产生状态到占空比的训练数据。神经网络拟合这个控制律，在线接收测量状态并输出占空比，经PWM控制电路。
