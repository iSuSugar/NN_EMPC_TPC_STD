# 09：回到原项目——A、B怎样变成EMPC控制函数

本课只沿原 `代码/EMPC1.m` 讲，不重新辨识、不改控制参数、不覆盖已有EMPC函数。你已经懂A、B的来源，现在看作者如何使用它们。

## 1. 先把A、B装进预测模型

原脚本当前启用：

```matlab
A = [0.9960 -0.0021; -0.0002 0.9996];
B = [0.7940; 0.1395];
C = [0 1]; D = 0;
model = LTISystem('A',A,'B',B,'C',C,'D',D);
```

等价C计算：

```c
il_next =  0.9960*il - 0.0021*vo + 0.7940*d;
vo_next = -0.0002*il + 0.9996*vo + 0.1395*d;
y = vo;  // C=[0 1]：受控输出取状态中的电压
```

**LTISystem只是告诉工具箱：我的预测函数长这样。** A、B用于预测；C挑选受控输出；D=0表示输出方程`y=C*x+D*u`里没有占空比的直接项。

## 2. 指定要预测几步

```matlab
N = 20;
Nsim = 10000;
```

`N=20`：一次优化向未来看20个模型离散步。

`Nsim=10000`：后面闭环演示运行10000步。两者不是同一件事，也不能直接当成微秒。

```matlab
model.u.with('block');
model.u.block.from = 1;
model.u.block.to = 5;
```

这段对预测序列第1～5个控制量施加分块设置，使这一段共享控制值，减少独立决策变量。它不表示真实电路每5步才测量一次。

## 3. 告诉优化器哪些方案不能选

原脚本设置：

```matlab
Xmin=[0;0]; Xmax=[92;200];
Ymin=0;     Ymax=200;
Umin=0;     Umax=1;

model.x.min=Xmin; model.x.max=Xmax;
model.y.min=Ymin; model.y.max=Ymax;
model.u.min=Umin; model.u.max=Umax;
```

| 约束 | 含义 |
|---|---|
| 0≤iL≤92A | 预测电感电流范围 |
| 0≤Vo≤200V | 预测电压范围 |
| 0≤d≤1 | 占空比范围 |

用C思路理解：若某个候选控制序列预测出超界状态，优化器就不能把它作为可行方案。

**这些是优化问题里的约束，不能替代实际电路限流。** 预测模型不完全准确，后面又用网络近似控制律，所以实际波形仍需要检查。

## 4. 在合规方案里，选哪个更好

先给目标：

```matlab
model.y.with('reference');
model.y.reference = 200;
```

再给权重：

```matlab
Qx = [3 0;0 0];
model.x.penalty = QuadFunction(Qx);
Qy = 3000;
model.y.penalty = QuadFunction(Qy);
```

把主要打分项理解成：

```c
float voltage_error = predicted_vo - 200;
float score = 3*predicted_il*predicted_il
            + 3000*voltage_error*voltage_error;
```

工具箱对预测时域内相关状态和输出项计总代价。**电压离目标远，扣分多；电流大，也扣分。** Qx第二个对角元素为0，并不表示不管电压，因为电压跟踪已由Qy处理。

例如某一步预测电流8A、电压199V，这两个主要项分别是 `3×8²=192`、`3000×1²=3000`。这只是解释权重，不是完整优化求解。

原脚本的占空比惩罚`model.u.penalty`一行被注释了，不应说作者此处启用了那项。权重来自设计和调试，不能由电容、电感直接计算出来。

脚本还用`Polyhedron('lb',...,'ub',...)`定义初始集合：可以先理解为用上下界描述一个范围，用于控制问题设置，不是硬件保护电路。

## 5. 建立MPC，再离线生成EMPC

```matlab
ctrl  = MPCController(model,N);
ectrl = ctrl.toExplicit();
```

第一行汇总“预测公式、目标、约束、权重、预测步数”，得到MPC问题。

第二行由工具箱离线求出显式控制律：把可行状态范围分成区域，每个区域对应占空比计算公式。

然后导出：

```matlab
ectrl.optimizer.trimFunction('primal',1);
ectrl.optimizer.toMatlab('Bstep_controller10.m','primal','obj');
```

保留用于当前执行的第一个控制量，生成MATLAB函数。`primal`对应控制解，`obj`用于多区域同时命中时的目标值比较。

**我们当前先读、调用项目已有的导出函数，不直接执行这一整段脚本重新生成文件。** 原辨识表与脚本参数的版本对应尚有缺口，不把已有函数宣称成这次原样重生成的结果。

## 6. 生成后的函数怎么用

调用形式：

```matlab
[d,region] = Bstep_controller10([il;vo]);
```

输入两个状态，返回占空比和区域编号。原已有函数的此前实际抽查：

| iL | Vo | 返回d |
|---|---|---|
| 0A | 0V | 1 |
| 10A | 190V | 1 |
| 10A | 200V | 约0.08269 |
| 100A | 250V | NaN，区域0 |

最后一行表示没找到可行区域，不能直接把NaN送给PWM。原函数内部检查区域不等式，必要时比较目标值，再代入区域公式。

不要把某个点的占空比当成稳态固定值。它是该瞬间状态下的控制命令，状态变化后要重新查询。

下一步就是原`train_sample.m`：反复调用这个函数，生成“状态→占空比”标签，再沿作者的训练脚本学习神经网络。
