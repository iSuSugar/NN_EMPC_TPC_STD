# 11：原网络怎样一步步算出占空比

这一课只拆原SISO模型已经保存的网络。它的有效结构是 **2个输入 → 40个隐层节点 → 1个输出**。参数来自原模型提取，不新训练。

## 1. 整体就是一个固定的C函数

```mermaid
flowchart LR
 A[电流iL、电压Vo] --> B[输入归一化]
 B --> C[40个节点：加权求和再tanh]
 C --> D[输出加权求和再tanh]
 D --> E[还原成占空比d]
 E --> F[PWM]
```

外部端口虽接4项，原保存网络的预处理删除了第3、4项恒定输入；有效计算只使用iL、Vo。

在线没有训练，也没有调用EMPC，只有下面这些固定运算。

## 2. 第一步：把输入缩放到相近的范围

保存的输入归一化范围近似为：电流0～144A、电压0～214V，映射到−1～1。

```c
double p0 = 2.0*il/144.0 - 1.0;
double p1 = 2.0*vo/214.0 - 1.0;
```

例如 `il=10A、vo=200V`：

```text
p0 ≈ −0.861111
p1 ≈  0.869159
```

**归一化只是换尺度，不是改变实际电流、电压，也不是限幅。** 如果输入超出保存范围，计算值也会超出−1～1。

上面数字为教学简写，正式复现要使用原保存的精确缩放参数。

## 3. 第二步：40个节点各算一个数

第j个节点：

$$h_j=\tanh(w_{j0}p_0+w_{j1}p_1+b_j)$$

```c
for (int j = 0; j < 40; ++j) {
    double z = W[j][0]*p0 + W[j][1]*p1 + bias[j];
    h[j] = tanh(z);
}
```

每个节点都看到同一对输入，但自己的权重、偏置不同，所以计算结果不同。

- 权重W：决定输入对该节点影响的大小和方向。
- 偏置bias：加上的固定数。
- tanh：非线性函数，把结果压到−1～1之间。

原`tansig`在数学上等价于tanh。其形式为：

$$\tanh(z)=\frac{e^{2z}-1}{e^{2z}+1}$$

理解时记住：`tanh(0)=0`，很大的正数接近1，很大的负数接近−1。C中直接调用`tanh()`，不必自行用指数实现。

为什么需要非线性？如果每一层只有乘加，多层最终仍可合成一个线性公式，难以拟合EMPC随状态区域改变的控制关系。

### 取原网络第一个节点看一次

其权重和偏置约为：

```text
W[0][0] = −12.261305
W[0][1] = −1.898678
bias[0] = 12.049947
```

输入10A、200V时：

```text
z0 ≈ −12.261305×(−0.861111)
     −1.898678×0.869159 + 12.049947
   ≈ 20.958041
h0 = tanh(z0) ≈ 1
```

这只是40个中间结果之一，还不是占空比。不能看到某个节点等于1就认为占空比等于1。

## 4. 第三步：把40个结果组合起来

输出层也有自己的权重和偏置：

$$s=b_{out}+\sum_{j=0}^{39}W_{out,j}h_j,\qquad a=\tanh(s)$$

```c
double s = output_bias;
for (int j = 0; j < 40; ++j) {
    s += output_weight[j]*h[j];
}
double a = tanh(s);
```

这个a仍在归一化空间，不直接送PWM。

原网络输出反归一化范围接近0～1，所以教学简写为：

```c
double duty = (a + 1.0)*0.5;
```

例如 `a=−1 → d=0`，`a=0 → d=0.5`，`a=1 → d=1`。它还原的是占空比，不是电压。

## 5. 把整个函数合起来

```c
// 原网络的计算结构；W、bias、output_weight来自保存的权重。
// 缩放数值在此简写。只展示推理，不含ADC、PWM和保护。
double network_duty(double il, double vo) {
    double p0 = 2.0*il/144.0 - 1.0;
    double p1 = 2.0*vo/214.0 - 1.0;
    double s = output_bias;

    for (int j = 0; j < 40; ++j) {
        double h = tanh(W[j][0]*p0 + W[j][1]*p1 + bias[j]);
        s += output_weight[j]*h;
    }
    return (tanh(s) + 1.0)*0.5;
}
```

不用保存40个h也能完成计算。每次读取新il、vo，调用同一个函数，得到新占空比；权重保持不变。

## 6. 用原保存参数实际算一个完整结果

本次用原提取的精确权重和缩放参数独立计算：

```text
输入：il=10A，vo=200V
输入归一化：p0≈−0.861111，p1≈0.869159
40个节点计算后，输出加权和s≈−1.076514
输出激活a≈−0.791903
反归一化：d≈0.104049
```

所以这一点网络给出约 **10.40%占空比**。此前现存EMPC函数在同一点给约 **8.27%**；两者并不完全相等，因为网络是近似控制律。

原权重计算在`il=0、vo=0`附近给接近100%的占空比。这与前面启动问题相关，不能把原网络直接当成已经完善的硬件启动控制。

此前独立MATLAB推理与原Simulink模块在1000个测试点最大绝对差约`5.09×10⁻¹³`，验证的是提取后的推理一致性。C编译、单精度误差和上板耗时尚未验证，到了部署步骤再处理对应文件。

## 7. 你现在应该能解释

> 网络就是一个保存了权重的数值函数：先归一化电流和电压，计算40个非线性节点，再组合结果并还原成占空比。训练已在线下完成，在线只做固定计算，然后把占空比交给PWM。

自查：

- [ ] 归一化处理的是尺度，不能代替限幅。
- [ ] 单个隐层节点不是占空比，输出层之后还要还原。
- [ ] 权重固定不代表占空比固定，输入改变时输出会改变。
