# 05：SIDO——一个电源，分别给电池和负载送能

这一步只搞懂一件事：**同一个电感，在一个开关周期内分三段工作。** SIDO表示单输入、双输出，这里的能量方向是 `Vs → VB + Vo`。

本课使用你的三张Visio图和项目原SIDO模型副本。电路和控制器未改，只增加测量支路；下方数值均来自实际运行，不是我新编的数据。

## 1. 先看三个阶段

整个模式中S3保持关断。先认两个时间边界：S2先关，S1后关。

| 阶段 | S1 | S2 | 电感电压 | 能量去向 |
|---|---|---|---|---|
| a：储能 | 开 | 开 | `Vs` | 电源给电感储能 |
| b：给电池送能 | 开 | 关 | `Vs − VB` | 电源和电感一起给电池送能 |
| c：给负载送能 | 关 | 关 | `−Vo` | 电感给输出送能 |

### a：先存进电感

![SIDO储能](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/07_SIDO_a.png)

回路：`Vs正端 → D1 → S2 → L → S1 → Vs负端`。

电池支路没有充电电流；输出由Co供电。忽略器件压降，电感两端是48V，所以电感电流上升。

### b：再给电池送能

![SIDO给电池送能](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/08_SIDO_b.png)

S2先关，S1仍开。回路：`Vs正端 → D1 → VB正端 → VB负端 → D2 → L → S1 → Vs负端`。

电流进入电池正端，表示充电。电感电压为 `48 − 72 = −24V`，电感电流下降；输出此时仍由Co供电。

**这一段是电源和电感一起给电池供能。** 电源48V低于电池72V，差额由电感释放能量补上。

### c：最后给输出送能

![SIDO给输出送能](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/09_SIDO_c.png)

S1也关断，回路变成：`L下端 → 输出支路 → D3 → D2 → L上端`。

电感电压为 `−200V`，电流下降得更快。电感送到输出的电流分给负载和Co；Co是否正在充电，还要看此刻电感电流是否大于负载电流。

判断斜率只用一个公式：

$$v_L=L\frac{di_L}{dt}$$

本模型 `L = 110μH`，所以三段理想斜率分别约为 `+0.436、−0.218、−1.818 A/μs`。符号判断上升/下降，绝对值判断快慢。

## 2. 占空比：两个开关，三个时间段

定义 `d1 = S1导通时间 / Ts`，`d2 = S2导通时间 / Ts`。正常三阶段要求 `0 < d2 < d1 < 1`。

```text
一个周期：  0              d2·Ts          d1·Ts       Ts
阶段：     |------ a ------|----- b ------|---- c ----|
S1：       |============= 导通 ==========|   关断   |
S2：       |==== 导通 =====|========== 关断 ==========|
```

所以三个阶段占周期的比例是：

$$a=d_2,\qquad b=d_1-d_2,\qquad c=1-d_1$$

**S1占空比是a+b；S2占空比是a。不要把阶段b的时长当成S1的占空比。**

用C逻辑理解理想时序，`phase`表示周期内已经走过的比例：

```c
// 只说明同步PWM的理想时序，不是实际驱动代码。
// d1、d2在一个周期内保持不变，且 0 < d2 < d1 < 1。
S3 = 0;
S1 = (phase < d1);
S2 = (phase < d2);
// phase < d2        : a，储能
// d2 <= phase < d1  : b，给电池送能
// d1 <= phase < 1  : c，给输出送能
```

## 3. 公式就是“三段电流变化加起来等于零”

稳态一个周期结束，电感电流回到起点。由 `Δi = vL·Δt/L`：

$$\frac{V_s d_2T_s}{L}+\frac{(V_s-V_B)(d_1-d_2)T_s}{L}-\frac{V_o(1-d_1)T_s}{L}=0$$

消去共同的 `Ts/L`，得到：

$$V_sd_2+(V_s-V_B)(d_1-d_2)-V_o(1-d_1)=0$$

整理：

$$\boxed{V_o=\frac{V_sd_1-V_B(d_1-d_2)}{1-d_1}}$$

毕业论文式(2-4)写成另一种形式：

$$V_o=\frac{V_sD_1+(V_s-V_B)D_2}{1-D_1-D_2}$$

**按该式的阶段时长含义，论文里的 `D1=a`、`D2=b`；对应上面的门极占空比是 `d2=D1`、`d1=D1+D2`。** 字母相似，含义不同；对照时先看它表示“阶段”还是“开关导通时间”。

原模型S1指令固定为 `d1=0.911`，代入 `Vs=48V、VB=72V、Vo=200V`，理想关系给出 `d2≈0.551`。这只是稳态理想估算，用来理解数量级；实际PWM还受采样、控制输出变化和器件模型影响。

## 4. 对应原Simulink模型

模型：`SIDO_VS_VBVo.slx`，原运行时长30ms。

| 要找的量 | 原模型位置 / 控制连接 |
|---|---|
| 电源48V | `DC Voltage Source` |
| 电池端72V | `DC Voltage Source1`，采用理想电压源表示电池端 |
| 输出电压 | `Voltage Measurement`，参考200V |
| 电感电流 | `Current Measurement3` |
| 电池电流 | `Current Measurement7` |
| S1 | `Constant1=0.911 → PWM Generator (DC-DC)2 → Mosfet` |
| S2 | `shu150（效果较好） → PWM Generator (DC-DC)1 → Mosfet1` |
| S3 | `Mosfet2`门极未连接，原模型按关断处理 |

因此这个现有模型是**固定S1占空比、控制器调S2**。它没有同时独立调节输出电压和电池充电电流，也没有用真实电池的SOC变化验证充电过程。

## 5. 已运行的结果：看波形，不靠猜

![SIDO全程实际仿真](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/02_仿真工程/03_SIDO/结果/waveforms.png)

20ms、25ms发生模型预设的负载支路开关事件。三个稳态窗口结果：

| 时间窗口 | 平均输出电压 | 平均电感电流 | 平均电池测量电流 |
|---|---|---|---|
| 16～19ms | 199.82V | 8.30A | −2.97A |
| 21～24ms | 199.42V | 15.70A | −5.26A |
| 26～29ms | 199.82V | 8.30A | −2.97A |

该电池电流传感器朝左，正方向对应电池向外供电；所以给电池送能时记录为负值。下面局部波形中，负电流恰好出现在 `S1=1、S2=0` 的b阶段，与电路分析一致。

![SIDO三个周期的门极和电流](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/02_仿真工程/03_SIDO/结果/cycles.png)

按每个周期从左到右看：**两管开，电流上升 → S2关，出现电池充电电流 → S1也关，电感电流快速下降。** 门极、电池电流和局部电感电流按0.1μs采样记录。

需保留两个问题，后续控制器与启动专题处理：

- 启动阶段电感电流峰值约147A，不能直接照搬到样机。
- 启动约0～3ms内出现 `S1=0、S2=1` 的额外状态，0.1μs采样共857点；上述三个稳态窗口未出现此状态。所以“三阶段”分析对应正常稳态时序，不能覆盖原模型整个启动过程。

这一步确认的是：原模型可以运行，稳态门极符合SIDO三阶段，电池支路和输出都有能量流入。全程启动性能及实际电池充电控制仍待验证。
