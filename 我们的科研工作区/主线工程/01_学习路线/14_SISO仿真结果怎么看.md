## 2. 启动：从初始状态到200V附近

目标是200V。原记录中：

| 量 | 导出采样点峰值 | 发生时刻 |
|---|---|---|
| 输出电压 | 236.1348V | 3.7575ms |
| 电感电流 | 211.4808A | 3.6200ms |

电压超调怎么算：

$$M_p=\frac{V_{peak}-V_{ref}}{V_{ref}}\times100\%$$

代入：

$$M_p=\frac{236.1348-200}{200}\times100\%\approx18.07\%$$

意思是启动时电压冲到了目标以上约18%。它后来回到200V附近，也不能抹掉这一段超调。

原EMPC设置脚本里写了92A上限，但实际导出电流峰值超过它。之前已经讲过：预测模型的约束，不会自动变成保存网络和实际电路的硬限流。这一问题保留，当前不自行改控制器。

211A是此模型的仿真记录，不是我们给样机选定的额定电流。

## 3. 稳态：不是问每个点是否刚好200V

取一段已经相对稳定的窗口，算平均电压：

$$\overline V_o=\frac{1}{n}\sum_{k=1}^{n}V_o[k]$$

平均电压相对参考的误差：

$$e_V=\overline V_o-200,\qquad
e_{rel}=\frac{|\overline V_o-200|}{200}\times100\%$$

已有三个窗口的结果：

| 时间窗口 | 平均输出 | 平均误差 | 相对误差 | 采样峰峰值 |
|---|---|---|---|---|
| 55～59ms | 199.9018V | −0.0982V | 0.0491% | 0.04354V |
| 65～69ms | 199.7282V | −0.2718V | 0.1359% | 0.04793V |
| 75～79ms | 199.9015V | −0.0985V | 0.0492% | 0.04367V |

所以可以说：**这三个窗口的平均输出接近200V，负载变化期间的稳态平均值存在小幅偏差。** 不能说输出在每个时刻都精确等于200V。

峰峰值怎么算：

$$V_{pp}=V_{max}-V_{min}$$

例如55～59ms，约`199.92049−199.87695=0.04354V`。

这只是导出采样点的峰峰值。原CSV记录间隔2.5μs，PWM周期10μs，不保证捕获所有开关瞬间的峰谷，不能把该数值直接当成连续时间真实纹波的完整测量。

## 4. 负载变化：控制器是否能承受扰动

原模型60ms、70ms有预设负载支路开关事件。

看第三张图：60ms后平均输出由约199.90V变为199.73V，70ms后恢复到约199.90V。电感电流也随负载需求改变。

这个过程仍然是Vs→Vo模式，**是负载变化，不是工作模式切换**。S1/S2仍由同一路PWM驱动，S3仍保持本模式的关断状态。

判断扰动响应时分三件事：

- 变化瞬间：电压偏离多少，有没有大幅尖峰。
- 变化之后：经过多久进入指定误差范围。
- 新稳态：是否仍接近目标，有没有持续偏差。

“恢复时间”必须先指定误差带，例如围绕200V的±1%，以及进入后需保持多久。不能看到线条平了就随口报一个时间，也不能把回到原稳态平均值与进入目标误差带混为一谈。

本轮尚未按原论文的同一口径核对恢复时间，因此这里不报未经核实的调节时间。

## 5. 用C理解这些指标

```c
// 对选好的稳态窗口统计，不把启动和稳态混在一起。
double sum = 0, vmin = samples[0], vmax = samples[0];
for (int k = 0; k < count; ++k) {
    double v = samples[k];
    sum += v;
    if (v < vmin) vmin = v;
    if (v > vmax) vmax = v;
}
double mean_v = sum / count;
double error_v = mean_v - 200.0;
double sampled_pp = vmax - vmin;
```

公式和这段代码是一回事。关键是先选对窗口，再说清采样间隔和指标含义。
