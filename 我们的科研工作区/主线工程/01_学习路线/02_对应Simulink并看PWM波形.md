# 02：对应Simulink，并看PWM波形

上一课已理解：Vs→Vo模式中，S1和S2一起导通时电感储能，一起关断时电感通过D2、D3放能。这次只把它对应到仿真。

## 2. 只沿这一条闭环看

```
电感电流、输出电压
       ↓
Delay、Delay1（保存的采样间隔2.5μs）
       ↓
Bus Creator：组合输入
       ↓
shu150和shu300以及变载：网络计算占空比
       ↓
PWM Generator (DC-DC)1：占空比转0/1脉冲
       ↓
Mosfet、Mosfet1：S1与S2同时开关
       ↓
电路状态改变，再采样
```

Bus Creator另外接了负载特征和200V参考。它是输入组合模块；本案例保存的网络预处理只保留前两项，后面讲网络时再展开。

以C程序理解：

```c
// 结构示意：ADC读取、控制更新和PWM计数有各自时序。
float il = read_current();
float vo = read_voltage();
float duty = controller(il, vo);
pwm_set_compare(duty); // PWM硬件不断按100kHz产生脉冲
```

`duty`是0～1附近的数值，PWM输出则是0或1。不要把占空比曲线和开关脉冲当成同一信号。

**PWM周期10μs，Delay配置2.5μs；它们是两个不同时间尺度。** 不能把所有仿真采样、控制执行都直接称为“一周期一次”。

### 补充：Delay究竟延迟什么

本模型的Delay/Delay1长度为1、采样时间为2.5μs，表示在离散更新时输出上一拍输入：`y[k]=x[k-1]`。假设初始值为0，可以用C模拟：

```c
static float previous = 0.0f;
float one_step_delay(float current) {
    float output = previous;
    previous = current;
    return output;
}
```

若在每个采样时刻先调用这个函数，再将返回值送给控制器：

| 时刻 | 本拍测得电流 | Delay输出（给控制器） |
|---|---|---|
| 0μs | 1A | 初始值0A |
| 2.5μs | 2A | 上一拍的1A |
| 5μs | 3A | 上一拍的2A |

它是数据在信号链里晚一拍，不是`sleep(2.5us)`。这也不意味着MCU执行计算一定花2.5μs；实际硬件还要分别考虑ADC采样/转换、软件计算、PWM何时更新比较值。

这种模块可用于表示一拍延迟或隔开直接反馈关系。当前文件没有足够说明其设计动机，所以这里只按实际模块配置解释，不把它声称为已测量的硬件延迟。

## 4. 先看3个周期，不看复杂的大图

![PWM与电感电流](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/02_仿真工程/01_SISO_VsVo/结果/门极与电流/pwm_inductor.png)

这张图从55ms开始截取30μs，约3个PWM周期，上面是S1和S2共同的门极信号，下面是电感电流。

- 门极为1：S1、S2导通，对应上一课阶段a。电感电流上升。
- 门极为0：S1、S2关断，对应阶段b。电感电流下降。
- 稳态附近，电流每周期上升再下降，总体在一个平均值附近波动。

电流不会因门极变0就瞬间变0；它通过二极管继续流动。这是上一课第2题在波形上的体现。

图上还能看到相邻周期的高电平宽度不同，因为闭环在动态调整占空比；不要要求每个周期都有完全相同的三角波。

这张PWM和电流图按0.1μs间隔记录。边沿位置只能在采样分辨率内判断，不应把它当作实际硬件死区或精确开关瞬间测量。

从上到下：输出电压、网络占空比、电感电流。

本次55～59ms窗口平均占空比约0.836，65～69ms约0.828，75～79ms约0.836。平均值并不表示占空比恒定；完整图显示它在稳态附近仍有明显逐次波动。它与理想稳态0.806的差异需要结合实际器件参数和控制波动继续解释，不能只归因为“损耗”。

先看输出是否接近200V，再看启动与负载变化时占空比怎样改变，最后看电流如何响应。稳态时的占空比应与上一课理想值0.806处于相近量级，但损耗、状态波动和控制器都会造成差异。

启动部分和稳态部分分别看。上一轮原基线已发现启动明显超调，我们保留问题后续处理；不要只截取稳态就说全程性能优秀。

## 6. 一个容易看错的地方

模型还有两个常数0.816及另外两个PWM块。经连线检查，它们没有驱动当前S1、S2的有效控制路径。真正驱动它们的是网络→PWM Generator (DC-DC)1。

判断谁在控制电路，**看接线，不能仅看哪个参数写着0.816。** 类似C工程有多个同名配置或示例变量，最终要看实际调用和赋值链。
