# 06：DISO——电源和电池一起给负载供能

先记一句话：**电源走一轮，电池再走一轮，共用同一个电感和输出。** DISO是双输入、单输出，能量方向为 `Vs + VB → Vo`。

这里的“一起”指两个输入都贡献平均功率，并不要求同一瞬间同时供电。

## 1. 四张图，其实是前面两个SISO模式拼起来

先按你的三开关电路图理解理论时序；第4节再对照实际模型。

| 阶段 | S1 | S2 | S3 | 电感电压 | 做什么 |
|---|---|---|---|---|---|
| a | 开 | 开 | 关 | `Vs = 48V` | 电源给电感储能 |
| b | 关 | 关 | 关 | `−Vo = −200V` | 电感给输出送能 |
| c | 关 | 开 | 开 | `VB = 72V` | 电池给电感储能 |
| d | 关 | 开 | 关 | `VB − Vo = −128V` | 电池和电感给输出送能 |

路径：`Vs正端 → D1 → S2 → L → S1 → Vs负端`。电感电流上升，Co给负载供电。

### b：电感给输出送能

**a+b就是已经学过的Vs→Vo。**

### c：换电池给电感储能

![DISO电池储能](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/12_DISO_c.png)

路径：`VB正端 → S2 → L → S3 → VB负端`。电池放电，电感电流上升；Co给负载供电。

### d：电池和电感一起给输出送能

![DISO电池时段放能](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/13_DISO_d.png)

S3关断，S2保持导通。路径：`VB正端 → S2 → L → 输出支路 → D3 → VB负端`。

电池72V不够达到输出200V，电感释放能量补上差额，所以 `vL=72−200=−128V`。

**c+d就是已经学过的VB→Vo。** 电池在c和d两个阶段都在放电；SIDO则是在它的中间阶段给电池充电。

## 2. 四段时间怎么分

定义电源工作时段为T1，电池工作时段为T2，一个完整调度周期 `T=T1+T2`。

- `Dv`：a阶段占T1的比例。
- `DB`：c阶段占T2的比例。
- `α=T1/T`：电源工作时段占整个周期的比例。

四段时长：

$$\tau_a=D_vT_1,\quad \tau_b=(1-D_v)T_1$$
$$\tau_c=D_BT_2,\quad \tau_d=(1-D_B)T_2$$

用C伪代码看这一轮时序：

```c
// t表示当前调度周期内的时间，只讲逻辑，不是驱动实现。
if (t < Dv*T1) {                  // a：电源储能
    S1=1; S2=1; S3=0;
} else if (t < T1) {              // b：电感给输出送能
    S1=0; S2=0; S3=0;
} else if (t < T1 + DB*T2) {      // c：电池储能
    S1=0; S2=1; S3=1;
} else {                         // d：电池+电感给输出送能
    S1=0; S2=1; S3=0;
}
```

注意：`Dv`以T1为分母，`DB`以T2为分母；它们不是直接以整个T为分母的门极占空比。例如S1全周期占空比是 `αDv`。

## 3. 公式仍然只靠电感电流一轮回到起点

四段满足 `Δi=vL·Δt/L`。稳态总变化为零，消去L：

$$V_s\tau_a-V_o\tau_b+V_B\tau_c+(V_B-V_o)\tau_d=0$$

将输出电压项移到右边：

$$V_s\tau_a+V_B(\tau_c+\tau_d)=V_o(\tau_b+\tau_d)$$

得到：

$$\boxed{V_o=\frac{\alpha D_vV_s+(1-\alpha)V_B}{\alpha(1-D_v)+(1-\alpha)(1-D_B)}}$$

分子来自两路输入，分母来自向输出送能的b、d两段时间。

如果进一步选择让T1和T2各自电流变化为零，就分别回到前面两个SISO的理想公式：

$$D_v=\frac{V_o}{V_s+V_o}=\frac{200}{248}\approx0.806$$
$$D_B=1-\frac{V_B}{V_o}=1-\frac{72}{200}=0.640$$

这需要额外满足“各时段独立平衡”的条件；总周期平衡本身不强制每个时段都独立平衡。

理想平均功率还应满足：

$$P_s+P_B=P_o,\qquad P_s=V_s\overline{i_s},\quad P_B=V_B\overline{i_B}$$

这里电池电流以放电为正。实际模型或样机还要计入损耗。**不能只看α或模型文件名就认定两路各出了多少瓦，要测电流再算。**

### 实际门极为什么与上面的表不同

![DISO实际门极与输入电流](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/02_仿真工程/04_DISO/结果/DISO_VS270W_VB30W/cycles.png)

门极图的四条曲线为避免重叠，分别增加了纵向偏移；每条曲线只看自己的高低电平。

实际原模型中：

- `Mosfet`和`Mosfet1`接同一PWM，两个门极完全相同。
- `Mosfet2`由另一路PWM经5μs的Transport Delay及比较器驱动。
- 输入支路额外串有`Mosfet5`，其门极与延时后的固定0.5占空比时序关联。
- 输出支路还有`Mosfet3、Mosfet4`以及负载切换开关。

因此，**前三节讲的是你的三开关示意图；这份原模型包含辅助开关，不能将前三节的门极状态逐项当成它的实测结果。** 局部图已经确认电源电流与电池电流在不同时间段出现，电感相应储能和放能；辅助开关、器件体二极管的具体通路留到模型接线核对时逐项解释。

启动输出峰值约230.66V，电感电流峰值约162.72A，启动控制仍须改进。

## 5. 另一个文件的结果暂不合格

`DISO_VS30W_VB270W.slx`也已按原参数运行100ms。它采用固定占空比驱动，测量电压在45～49ms约为 **−116.94V**，没有得到200V。即使暂时只看电压绝对值，也只有约117V。

后续第18章已核对：这份SLX的输出电压测量端子相对另一份接反，负号由测量方向解释；原25拍延时实际约2.5μs，电容电压**幅值仍只有约117V**。第18章第5节的内存临时对照将驱动`Mosfet2/Mosfet5`的`Delay`单独改为50拍后，两个稳态窗口约199V，定位了原低电压的主要时序原因；原SLX和基线仍不改。旧`run_diso.m`对两模型统一计算`mean(Vo²)/300`，但本模型实际两负载电阻为148.148Ω和1333Ω，该旧CSV列不能当真实负载功率或效率依据。原模型不能当成“30W+270W已成功复现”。
