# 04：运行另外两个SISO仿真

上一课的两个电路模式，现在已在原模型副本上实际运行。只新增测量支路，未重训控制器，也未修改电路参数。先确认门极接线，再看受控端口的波形。

## 1. VB→Vo：看S3和输出200V

原模型运行时段0～200ms，电池端电源为72V，输出参考为200V；120ms、140ms发生预设负载支路开关事件。

实测门极：

```c
S1 = OFF;   // 记录全程为0
S2 = ON;    // 记录全程为1
S3 = PWM;   // 记录包含0和1
```

与第03课一致：S3导通时电池给电感储能；S3关断时电池和电感给输出送能。S2在两个阶段都保持导通。

![VB到Vo实际仿真波形](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/02_仿真工程/02_SISO_VBVo与VsVB/结果/SISO_VB72_Vo200/waveforms.png)

从上到下看：输出电压、电感电流、网络占空比、输出电压局部放大。

| 稳态窗口 | 平均输出电压 |
|---|---|
| 115～119ms | 约200.03V |
| 125～129ms | 约199.88V |
| 145～149ms | 约200.03V |

负载增加时，电感电流增大，控制器改变占空比，输出仍在200V附近；负载恢复后，输出回到原稳态附近。这一过程仍是VB→Vo模式，属于负载变化，不是模式切换。

全程启动电压峰值约270.17V、电感电流峰值约245.89A。先保留问题，后续专门处理启动；目前不能据稳态接近参考就宣布全程性能合格。

## 2. Vs→VB：看S2和受电端72V

原模型运行0～50ms，输入电源48V，受电端电压参考72V；30ms、40ms发生预设负载支路开关事件。

实测门极与接线：

```c
S1 = ON;    // 记录全程为1
S2 = PWM;   // 记录包含0和1
S3 = OFF;   // 原模型门极未连接，没有独立门极记录
```

与第03课一致：S2导通时电感储能；S2关断时电源和电感向受电端送能。S1在两个阶段均保持导通。

![Vs到VB实际仿真波形](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/02_仿真工程/02_SISO_VBVo与VsVB/结果/SISO_VS48_VB72/waveforms.png)

此图的受控电压来自`Voltage Measurement1`，是VB端口；不是右侧Vo输出电压。

| 稳态窗口 | 平均受电端电压 |
|---|---|
| 25～29ms | 约71.94V |
| 35～39ms | 约72.02V |
| 45～49ms | 约71.94V |

启动端口电压峰值约93.67V、电感电流峰值约87.24A。30ms负载事件也存在瞬态峰值，底部局部放大采用71～73V显示范围，超出范围的部分请查看第一幅全程图或原数据；该局部图不用于读完整瞬态峰值。

原模型用电阻、电容表示受电端口行为，未接入完整真实电池模型。本次确认的是端口电压控制与能量路径；不能把这些波形直接当成实物电池充电实验。

新增To Workspace记录电压、电流、占空比及已连接门极，间隔2.5μs。Array格式只含信号值，脚本按配置的固定间隔生成时间列。门极记录每周期约4点，可以确认固定开关状态及存在PWM翻转，但不适合测精确边沿或占空比。

数据位于各自results目录：output.mat保存完整仿真输出，port_trace.csv/current_trace.csv/duty_trace.csv保存两列时间与信号，windows.csv保存稳态统计，run.txt保存门极来源及运行警告。

这些仍然使用原来的网络参数；本轮没有从头设计MPC、生成EMPC或重新训练网络。原模型的除零和未连接端口警告已记录。
