# 08：数据从哪来，送到哪去

先记住：**辨识电路的数据来自仿真；训练控制网络的占空比标签来自EMPC计算。** 两者都是五列，但第三列和第五列的含义不同。

本课沿SISO_VS48_Vo200模型与算法讲解。已有MAT是项目保存的历史数据；本次只读检查，不重新生成或覆盖它们。

## 1. 第一张表：学“电路下一步怎么变”

`model_train.mat`里面的`model_train`用于辨识预测模型。

| 第1列 | 第2列 | 第3列 | 第4列 | 第5列 |
|---|---|---|---|---|
| iL(k) | Vo(k) | d(k) | iL(k+1) | Vo(k+1) |
| 当前电流 | 当前电压 | 当前使用的占空比 | 下一步电流 | 下一步电压 |

数据链：

```text
设定电路、负载和PWM → 运行Simulink → 导出iL、Vo及控制记录
                                                ↓
                           配对当前样本与下一步样本 → model_train
```

这类数据目前是仿真数据，不是样机测量。获得实物后，可以采集真实电流、电压和控制记录，按相同含义构建实测辨识数据。

### k与k+1就是数组相邻行

原 `model_calculate.m` 的主要逻辑为：

```matlab
model_train(:,1) = iL(1:N,2);
model_train(:,2) = Vo(1:N,2);
model_train(:,3) = 0.585;
model_train(:,4) = iL(2:N+1,2);
model_train(:,5) = Vo(2:N+1,2);
```

原脚本N写为18000。这里假设iL、Vo是两列数组，第1列时间、第2列信号值；第三列则直接写入固定占空比0.585。

用C来理解：

```c
typedef struct {
    float il, vo, duty;
    float il_next, vo_next;
} ModelSample;

for (int k = 0; k < N; ++k) {
    rows[k] = (ModelSample){
        il[k], vo[k], duty[k], il[k+1], vo[k+1]
    };
}
```

注意：C例子保存实际duty[k]，原脚本使用固定数值。只有原采集过程确实保持同一占空比，写入固定值才成立。不能把闭环运行中变化的占空比统一写成0.585。

配对还必须保证：电流、电压时间对齐，采样间隔明确，duty[k]对应这一段状态变化。相邻数组行不自动等于一个PWM周期。前面新增的To Workspace采用Array格式时只保存值，不能直接照抄“取第2列”的旧脚本。

## 2. A、B是怎样从这张表求出来的

模型假设：

$$i_L(k+1)=a_{11}i_L(k)+a_{12}V_o(k)+b_1d(k)$$
$$V_o(k+1)=a_{21}i_L(k)+a_{22}V_o(k)+b_2d(k)$$

每一行都给系数提供一组方程。样本通常多于未知系数，用最小二乘寻找让总体预测误差平方和较小的系数。

把输入和目标组织为：

$$X=\begin{bmatrix}i_L(1)&V_o(1)&d(1)\\i_L(2)&V_o(2)&d(2)\\\vdots&\vdots&\vdots\end{bmatrix},\quad
Y=\begin{bmatrix}i_L(2)&V_o(2)\\i_L(3)&V_o(3)\\\vdots&\vdots\end{bmatrix}$$

求 `X·Θ≈Y`：

```matlab
X = model_train(:,1:3);
Y = model_train(:,4:5);
Theta = X \ Y;    % MATLAB最小二乘求解，不是逐项相除
```

结果的排列是：

$$\Theta=\begin{bmatrix}a_{11}&a_{21}\\a_{12}&a_{22}\\b_1&b_2\end{bmatrix}$$

第一列用于预测电流，第二列用于预测电压。再整理成：

$$A=\begin{bmatrix}\Theta_{11}&\Theta_{21}\\\Theta_{12}&\Theta_{22}\end{bmatrix},\qquad
B=\begin{bmatrix}\Theta_{31}\\\Theta_{32}\end{bmatrix}$$

原脚本的`regress(y,X)`是同类线性回归；它当前只选第5列预测Vo。若要得到完整A、B，还须对第4列iL_next求一遍，或者像上面同时求两列。

**这些系数是拟合出来的，不是神经网络控制器输出的，也不是把L、Co直接填入矩阵。** 当前回归没有额外增加常数项。

2026-10-12理解校正：恒定占空比是部分原辨识数据的采集方式，不是最小二乘必须满足的条件。若d恒定且非零，原无额外常数项回归中的Bd相当于固定偏置；X是否满秩仍取决于状态数据。即使数值上能拟合，也不能仅凭这组固定d数据就证明改变d后的输入响应正确。若增加独立常数项，它与恒定d列共线；若采用工作点增量且Δd始终为零，则无法由这批数据辨识增量B。当前先理解原数据含义，不擅自更换原辨识表或重训。


## 3. 已有文件实际保存了什么

已核对原副本：

- `model_train`实际是 **4000×5**，第三列全部为 **0.816**。
- 当前生成脚本却写 **18000行、0.585**；因此不能直接说该脚本原样生成了这个MAT。
- 对已有4000行求最小二乘，得到下面的近似系数。

本次还读取了同一MAT内保存的原iL、Vo数组：各为4001×2，时间列相邻间隔均为 **2.5μs**。这是这份历史数据的记录间隔，不能据此自动确认另一版EMPC参数的离散步长。

例如历史表中的一条真实记录（四舍五入）：

| iL(k) | Vo(k) | d(k) | iL(k+1) | Vo(k+1) |
|---|---|---|---|---|
| 0.1447A | −0.0001V | 0.816 | 0.3792A | −0.0002V |

这条记录来自启动附近，微小负电压保留原数据，不人为改成零。

| 输入项 | 预测下一步iL的系数 | 预测下一步Vo的系数 |
|---|---|---|
| 当前iL | 0.9952 | 0.0021 |
| 当前Vo | −0.0046 | 0.9999 |
| 当前d | 1.2018 | −0.0051 |

这对应近似：

$$A_{\text{本数据拟合}}\approx\begin{bmatrix}0.9952&-0.0046\\0.0021&0.9999\end{bmatrix},\qquad
B_{\text{本数据拟合}}\approx\begin{bmatrix}1.2018\\-0.0051\end{bmatrix}$$

它与第07课原`EMPC1.m`写入的A、B不同。现在确认的是“辨识方法和这份数据的拟合结果”，还没有确认“原控制器所用A、B的准确采集版本”。

同一批数据上的预测RMSE约为 **1.66A、0.196V**，这只是拟合误差，不是独立测试结果。固定占空比下即使矩阵数值满秩，也不足以证明模型能准确预测其他占空比或负载。后续要用独立轨迹和不同控制激励验证。

## 4. 第二张表：学“现在该输出多少占空比”

`shu150.mat`中的`shu150`属于控制律标签表：

| 第1列 | 第2列 | 第3列 | 第4列 | 第5列 |
|---|---|---|---|---|
| iL | Vo | 附加特征 | Vref | d_EMPC |
| 查询状态 | 查询状态 | 按生成工况设置 | 参考电压 | EMPC计算结果 |

与第一张表不同：**这里第五列是当前状态应使用的占空比，不是下一步电压。**

### 标签如何生成

原 `train_sample.m` 在状态平面上逐点查询：

```c
// 概念示意：EMPC要用同一工况、同一版本的已导出控制律。
for (int v = 0; v <= 500; ++v) {
    for (int i = 0; i <= 230; ++i) {
        float il = 0.4f*i;
        float vo = 0.4f*v;
        float d = empc_control(il, vo);
        if (isfinite(d)) {
            save_training_row(il, vo, feature, 200.0f, d);
        }
    }
}
```

当前原脚本范围为 `iL=0:0.4:92`、`Vo=0:0.4:200`，共有 `231×501=115731` 个候选点。它调用 `Bstep_controller10([iL;Vo])`，删除含NaN的行，当前保存名为`shu200`。

因此这些标签不需要逐点跑电路仿真，也不需要实物实验；它们是对已导出EMPC控制函数的计算查询。

已有`shu150`则有 **191379行**，状态范围到144A、214V，第三列固定1.333、第四列固定200。它与当前脚本的范围、文件名不同。先前抽查其中2000个点，现存EMPC函数输出与保存标签一致；这是已有数据的数值对应证据，不证明当前脚本就是它的原始生成配置。

第三列在原闭环中对应负载相关特征，在线连接计算形式是 `Vref/(Vo/io)`。已有表中它是固定值；不能仅凭1.333反推全部实际负载接线和数据来源。

例如另一条真实控制标签是 `iL=9.6A、Vo=214V、feature=1.333、Vref=200V → d≈0.1175`。这里214V是查询状态，0.1175才是EMPC占空比标签；没有“下一步电压”这一列。

## 5. 这张标签表怎样变成网络

原 `myguiyihua.m` 的主要结构是：

```matlab
load('changeR1.mat');              % 合并后的控制标签表
a1 = changeR1(randperm(size(changeR1,1)),:);
inputn  = a1(:,1:4)';              % 每一列一个样本
outputn = a1(:,5)';                % 目标占空比
net = newff(inputn,outputn,8,{'tansig','tansig'},'trainlm');
net = train(net,inputn,outputn);   % 调整权重，使输出接近EMPC标签
gensim(net);                      % 生成Simulink网络模块
```

MATLAB网络采用“特征×样本”的矩阵布局，所以这里要转置。对你熟悉的C数组来说，仍然是一条训练记录含四个输入和一个目标值。

原脚本设置8个隐层节点，但已跑通模型保存的是40个节点；本案例合并文件和完整训练配置也未齐。因此现在可以解释训练逻辑、运行已有网络，尚不能宣称已经从头重训复现了同一个网络。

另外，原脚本把整张表传给`train()`，又取其中部分行当外部测试。这个子集没有预先排除在训练总输入之外，不能据此认定是独立测试集；需要核对训练内部划分并重新定义独立测试。

## 6. 把整条数据流讲给老师听

```text
第一张表：当前状态+d → 下一步状态
        ↓ 拟合
预测模型A、B → 定义MPC → 导出EMPC函数
                                ↓ 扫描状态、计算标签
第二张表：当前状态等输入 → EMPC占空比
        ↓ 训练

```

## 2026-10-12：重新串起辨识与控制

用户明确表示尚不会从数据配对、求系数接到MPC；本节先建立主线，不认定此前“看懂”已通过独立解释。

以Vs→Vo两状态、一占空比模型为例，辨识表每行是 `[iL[k], Vo[k], d[k], iL[k+1], Vo[k+1]]`。前三列是原因/输入，后两列是下一拍结果。采样时刻和占空比作用区间要对齐。

假设下一拍电流为 `a11*iL + a12*Vo + b1*d`，下一拍电压为 `a21*iL + a22*Vo + b2*d`。最小二乘拟合这六个系数；A收纳四个状态系数，B收纳两个占空比系数。A/B描述电路怎样变化，不是神经网络权重。原数据固定d的辨识局限见第2节，不更换原表。

MPC用模型预测候选占空比造成的未来状态，依据参考、代价和约束选占空比；EMPC离线预先求控制律；从EMPC查询状态对应的控制标签，再训练网络近似该控制律。当前原保存网络已经训练好，但全生成链独立重建尚未完成。网络在线仍须输入实时测量状态。
