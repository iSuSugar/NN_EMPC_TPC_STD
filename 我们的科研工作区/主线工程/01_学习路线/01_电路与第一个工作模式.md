# 01：电路与第一个工作模式

这次从毕业论文重头讲。先看懂电路，再运行对应仿真。读完本文，你应能说明三个端口的用途、模式与模态的区别，以及48V如何变为200V。

## 1. 整个项目在做什么

**用一套功率电路连接电源、蓄电池和负载，再用控制算法调整开关占空比，使系统在供电来源或负载改变时仍能正常工作。**

先研究电路如何搬运能量；后面才研究如何自动选择占空比。本文先把一个固定模式讲清楚。

## 2. 认清总电路

![三端口变换器总拓扑](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/00_Topology.png)

| 图中符号 | 是什么 | 在这里做什么 |
|---|---|---|
| Vs | 输入电源端口电压 | 代表外部供电来源，例如光伏侧；基线仿真用48V电源 |
| VB | 蓄电池端口电压 | 接收能量充电，或提供能量放电；标称72V |
| Vo、Ro | 输出电压、负载电阻 | 向负载供电，输出参考200V |
| S1、S2、S3 | 三个受控开关 | 通过导通/关断改变电流路径 |
| D1、D2、D3 | 三个二极管 | 在相应偏置条件下提供单向电流路径 |
| L | 电感 | 电流增加时储能，电流减小时释放能量 |
| Co | 输出电容 | 缓冲输出能量，减小电压波动 |

电感的关键关系是 **电压决定电流变化速度**：`diL/dt = vL/L`。电容的关键关系是 **电流决定电压变化速度**：`dVo/dt = iC/Co`。这两条关系会贯穿后续模型推导。

注意图中Vo的“+”在下、“−”在上。本文把Vo作为正的端口电压数值，例如200V；若以底部导线为0V，上端节点电位就是−200V。看回路时必须按图中极性，不能习惯性地把上方节点当成+200V。

## 3. 三类模式、五种能量流向

这里“输入/输出”按能量进出变换器区分。电池充电时是能量输出端，放电时是能量输入端。

| 类别 | 能量流向 | 一句话理解 |
|---|---|---|
| SISO：单输入单输出 | Vs→Vo | 电源单独给负载供电 |
| SISO | VB→Vo | 电池单独给负载供电 |
| SISO | Vs→VB | 电源给电池充电，负载不参与供电 |
| SIDO：单输入双输出 | Vs→VB和Vo | 电源同时带负载并给电池充电 |
| DISO：双输入单输出 | Vs和VB→Vo | 电源与电池一起给负载供电 |

**工作模式回答“谁给谁供电”；模态回答“这一小段时间里，开关怎样导通”。**

例如整个仿真一直处于Vs→Vo模式，但每个PWM周期内部仍反复经历储能和放能两个模态。以后说“模式切换”，通常指Vs→Vo变成SIDO等，而不是每个PWM周期里的开关翻转。

## 4. 第一个模式：Vs→Vo

### 阶段a：电源给电感储能

![Vs到Vo：储能阶段](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/01_SISO_VsVo_a.png)

S1、S2导通，S3关断。沿红色箭头读：

**电源正端 → D1 → S2 → L → S1 → 电源负端。**

电源给电感加上正电压，电感电流上升。此时D3不向输出送电，右侧负载由电容Co维持供电；电容储能下降。

理想器件下忽略导通压降：

$$v_L=V_s,\qquad \frac{di_L}{dt}=\frac{V_s}{L}.$$

这就是“电感充电”的具体含义：电流增加，储能 $E_L=Li_L^2/2$ 增加。

### 阶段b：电感给输出释放能量

![Vs到Vo：放能阶段](D:/Project/NN_EMPC_TPC/我们的科研工作区/主线工程/01_学习路线/images/02_SISO_VsVo_b.png)

S1、S2、S3全部关断。但电感电流不能瞬间消失，于是通过D2、D3形成新的回路：

**L下端 → 输出支路 → D3 → D2 → L上端 → L内部向下。**

这里是沿一个闭合回路选择起点来描述；电感电流方向仍向下。电感向输出提供能量，电流下降。

按总图的电感和输出电压极性：

$$v_L=-V_o,\qquad \frac{di_L}{dt}=-\frac{V_o}{L}.$$

此时输出支路得到电感电流；Co的电流取决于电感送来的电流与负载电流之差，因此不能笼统说Co在整个阶段始终充电。

| 模态 | S1 | S2 | S3 | 电感电压 | 电流趋势 |
|---|---|---|---|---|---|
| a：储能 | 开 | 开 | 关 | +Vs | 上升 |
| b：放能 | 关 | 关 | 关 | −Vo | 下降 |

“开”在表中表示导通，不表示电路断开。

## 5. 一个周期多久，占空比是什么

开关频率 $f_s=100\,\mathrm{kHz}$，因此一个周期：

$$T_s=\frac1{f_s}=10\,\mu\mathrm{s}.$$

占空比D是阶段a占整个周期的比例：

$$t_a=DT_s,\qquad t_b=(1-D)T_s.$$

对应你熟悉的定时器逻辑，可以理解为：

```c
// 概念伪代码：这里的ON/OFF表示器件状态，不对应具体GPIO电平。
// 实物还需驱动、保护和实际定时器配置。
if (phase_in_period < duty) {
    S1 = ON; S2 = ON; S3 = OFF;  // 电感储能
} else {
    S1 = OFF; S2 = OFF; S3 = OFF; // 电感放能
}
```

PWM负责循环执行两个阶段。控制算法负责决定`duty`取多少。

## 6. 推导毕业论文式(2-1)

稳态时，电感电流在一个完整周期后的变化为0：上升多少，就下降多少。这叫电感伏秒平衡。

阶段a电流变化：

$$\Delta i_a=\frac{V_s}{L}DT_s.$$

阶段b电流变化：

$$\Delta i_b=-\frac{V_o}{L}(1-D)T_s.$$

令两者相加为0，消去L和Ts：

$$DV_s-(1-D)V_o=0.$$

整理得到毕业论文式(2-1)：

$$\boxed{\frac{V_o}{V_s}=\frac{D}{1-D}}.$$

因此48V输入、200V输出所需的**理想稳态占空比**：

$$D=\frac{V_o}{V_s+V_o}=\frac{200}{248}\approx0.80645.$$

对应阶段a约8.0645μs，阶段b约1.9355μs。这里是理想稳态计算值；启动过程中电感电流尚未周期平衡，闭环控制也会动态改变占空比。

## 7. 电容如何维持输出

电阻负载电流 $i_o=v_o/R_o$。

阶段a只有电容给负载供电，所以：

$$C_o\frac{dv_o}{dt}=-\frac{v_o}{R_o}.$$

阶段b电感电流进入输出支路，所以：

$$C_o\frac{dv_o}{dt}=i_L-\frac{v_o}{R_o}.$$

这两条分别表示：电容在补负载缺口；电容接收电感送来与负载消耗之间的差额。后面建立控制模型，就是把这些阶段方程按占空比组合起来。
