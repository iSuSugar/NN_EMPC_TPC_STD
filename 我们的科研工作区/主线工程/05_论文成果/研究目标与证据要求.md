# 研究目标与证据要求

目标：完成可理解、可追溯的原项目复现，建立实物样机，形成有独立贡献和充分证据的研究，争取电力电子领域高水平期刊。毕业论文是参考，不是研究范围上限。当前尚未选定目标期刊或确认创新点，不承诺录用。

以TPEL作为证据标准的一个参考：其官方政策通常要求完整硬件试验；投稿需有原创内容，会议稿扩展须有新增贡献并说明既有发表。具体目标确定后再按该刊规则核对。来源：[TPEL官方作者说明](https://www.ieee-pels.org/publications/transactions-on-power-electronics/)、[TPEL投稿指南](https://www.ieee-pels.org/wp-content/uploads/2025/07/REV-2025-TPEL-Guidelines-for-Manuscript-Submission.pdf)。以下是本项目的研究规划，并非所有期刊统一强制清单。

## 1. 三条线各自验收

| 线 | 要交付什么 | 完成依据 |
|---|---|---|
| 原项目复现与理解 | 全模式原理、公式、参数、代码、数据、单模式/变载/切换和基线对比 | 对应原版本的解释与可重跑记录，差异定位；不是只打开SLX |
| 我们的样机 | 功率电路、驱动、采样、控制固件、时序、保护、热设计和实验平台 | 从低能量调试逐步到额定工况，实测功能/性能/效率与边界 |
| 我们的研究贡献 | 可证伪的问题、与现有工作的差别、方法、理论或机制解释、公平对比和消融 | 新结果支撑明确贡献；仅复制网络、加硬件或美化图不自动构成创新 |

原作者数据、工作副本仿真、新方法数据、实物数据分开标记。基线先保留；后续创新在单独版本实现，比较时固定工况与评价方法。

## 2. 原论文之外需要补充的内容

| 主题 | 本项目要做的工作 | 留下的证据/验收点 |
|---|---|---|
| 创新与定位 | 阅读最相关的近期原始论文，核对已经做过什么，提出一个主要问题和方法 | 文献对比表、可检验假设、贡献与结论对应；检索前不声称首创 |
| 模型可信度 | 理想/非理想模型、CCM/DCM边界、寄生与参数不确定性、各模式状态和过渡 | 方程假设与误差范围；与仿真/实测对照；是否研究DCM由工作范围决定 |
| 控制约束与切换 | 占空比合法性、过流/过压、切换路径与状态连续性、软启动、域外输入策略 | 峰值、有效域与失败工况；对宣称的稳定性/约束性质给出相应证明或边界分析，不能仅凭波形保证全局稳定 |
| 训练与泛化 | 数据来源与覆盖、独立训练/验证/测试、按工况留出、随机种子与版本、归一化范围、标签合法性 | 无评估泄漏；不同种子/留出工况结果；误差分布与闭环影响，不能只报MAE |
| 嵌入式实时性 | MCU资源、浮点/定点、推理精度、ADC采样相位、延迟/抖动、PWM更新/死区 | 实测最坏计算时间与完整控制周期，Flash/RAM，执行精度和失效处理 |
| 硬件工程 | 额定功率/端口范围、器件应力、L/C、驱动、传感器校准、接地布线、散热、保护和电池接口 | 原理图/BOM/固件版本与测试记录；电池充电策略不得由RC端口稳压代替 |
| 公平对比 | 对照调参后的PI/PID、直接EMPC或MPC等与主张相关的基线 | 相同功率级、扰动、采样延迟、约束和测量口径；无法在同MCU运行时说明比较边界 |
| 消融与原因解释 | 去掉核心新增机制，固定其余设置；检查性能来自哪里 | 至少覆盖主要贡献对应的消融；不用更大网络掩盖方法效果 |
| 实验矩阵 | 启动、五模式稳态、双向模式切换、负载/输入变化、参数失配与测量扰动、边界 | 每组工况/重复次数/指标事先登记；不是把所有可能实验无限铺开 |
| 可信测量 | 仪器与带宽、探头/采样、校准、不确定度、同步、原始波形与功率测量 | 可追溯数据、重复结果与误差；功率/效率定义完整，三端口充电与放电符号一致 |
| 可复现与写作 | 公式符号、完整参数、版本、配置、图表生成、数据去向、失败结果与限制 | 图表能回到原始数据；结论不超出证据；引用原毕业论文/会议稿及来源 |

控制对比、消融和实验范围要围绕最后确定的贡献收敛；没有理由的实验不做。与主张有关的证据不能省。

## 3. 候选问题，尚未确认创新

原模型已出现启动超调/大电流、切换版本差异、训练评估重叠，以及网络近似与约束之间的缺口。可以围绕“具有约束与实时预算的模式切换控制”评估研究机会。

候选方向：在保留快速网络推理的同时，用可解释的切换安排和约束处理降低切换/启动峰值，并测量其嵌入式代价。必须先查现有研究、定位基线问题，再决定是否值得做；修复错接线本身不能当作算法创新。

若主张“网络更快”，需时间/资源数据；若主张“更安全或满足约束”，需约束依据和边界测试；若主张“更鲁棒”，需失配/扰动对比；若主张“泛化”，需未参与训练的工况。各结论都要对应专门证据。

## 4. 执行次序和当前范围

1. 当前：三个SISO、SIDO、DISO、三组切换与五份原PID比较模型均已做第一遍原参数运行；第19章图4-19版本/方向冲突、第20章双电路公平性及论文逐图仍待核。各模式未验收项留对应章。DISO固定命令案例的延时单因素诊断见第18章，不等于完整修复。
2. 各模式内同时对应应力、参数、损耗、算法与数据版本；待解决项归入该模式，不作为跳读后另补的课程。
3. 各模式仿真与理解阶段完成后，先做给老师的阶段汇报PPT；同时收敛创新点、比较方法和实验矩阵，为样机留好测量接口。
4. 与老师确认硬件方案，完成固件与样机，获得主贡献对应的硬件证据及对比/消融。
5. 再完成SCI论文正文与投稿，老师指导。研究记录、图表索引和文献笔记从现在维护。

目前硬件、创新检索、全模式精确重训和独立泛化验证均未完成。此文件是计划，不是已有研究成果。
