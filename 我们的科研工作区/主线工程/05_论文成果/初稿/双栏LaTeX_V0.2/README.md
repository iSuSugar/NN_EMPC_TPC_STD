# 中文双栏论文 V0.2

主文件为 `main.tex`，编译后为 `main.pdf`。全文黑色，正文双栏；电路、系统结构与大型结果图按需要跨双栏。包含46个编号公式、16组图、10张表和14条参考文献。其中图1—12为机理/结构图或基于既有保存数据的结果图，图13—16是硬件实测替换位置；没有预填缺少的实测数据。

## 怎样改

1. 在支持XeLaTeX的编辑器打开 `main.tex`；Overleaf中将编译器设为XeLaTeX。
2. 本地TeX Live或MiKTeX环境中，在此目录运行两次 `xelatex main.tex`。采用ctexart、Fandol字体与常用宏包，无本项目其他仿真目录的编译依赖。
3. 修改正文与公式直接编辑 `main.tex`。`equations.tex`提供按正文顺序汇总的公式源，便于查询，不单独编译。
4. 六张机理/结构图的TikZ源在 `figures/fig01_topology.tex` 至 `fig06_timing.tex`（按文件名查找）。其余结果图同时保存矢量PDF和450 dpi PNG，LaTeX使用PDF；Word版使用PNG，数学公式为可编辑原生公式。
5. 硬件图13—16：将对应 `center` 占位块替换为正常的 `figure` 环境，并使用 `\includegraphics[width=\linewidth]{文件名.pdf}`；同步填写表8—10的待补项。需要跨栏时使用 `figure*`、图宽改为 `\textwidth`，并把原 `\captionof{figure}` 改为 `\caption`。

单输出网络为4–16–8–1，DISO为4–16–8–2。门极序列图是三开关理想/数字时序示意，不应与额外辅助MOS的仿真图混作逐拍等同。硬件实验章节按完整论文结构安排，最终照片、波形、资源、时延和对照结果应据原始实测填写，并据此更新摘要与结论。
