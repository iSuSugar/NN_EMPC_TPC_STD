## 1. 本次确定的范围

1. 开环：Vs→Vo、VB→Vo、Vs→VB、SIDO、DISO 五模式逐个验证；随后验证工作模式切换。
2. 闭环：五模式分别做 PI 与 NN-EMPC 的稳态、启动、负载扰动对比；输入扰动在设备允许时做。闭环工作模式切换选择代表场景，不要求遍历所有排列。
3. 操作：串口选择模式、设置开环占空比、启动/停止、请求切换；按键退出日常选模式用途，保留本地停止功能。故障保护不能依赖电脑、串口或操作人员反应。
4. 固件最终按 OPEN、PI、NN 三个目标分别生成 bit，复用 ADC、调制、保护、命令接口。PI 与 NN 分别烧录、同条件对比，不要求运行中互切控制算法。
5. ADC 不需要先经网口才能闭环。串口用于操作及慢速状态；示波器原始波形用于本方案主体证据。网口保留，遇到逐周期内部数据分析需求再用。

正式仿真基线：[48_72_120_C220_16_8](D:/Project/NN_EMPC_TPC/48_72_120_C220_16_8)。48/72/120 V、L=110 µH、Co=220 µF、100 kHz 是目标参数，实际焊装值与额定值须填写确认，不能代替首轮低压试验配置。

## 3. 端口、供电及隔离边界

### 3.1 物理测点定义（以网络名为准）

| 名称 | 正端 | 负端/参考端 | 含义 |
|---|---|---|---|
| Vs，J1 | VS_POS | VS_NEG | 输入源电压 |
| VB，J2 | VB_POS | VB_NEG | 电池端电压 |
| Vo，J3 | OUT_POS（图中与 IL_OUT 相连） | OUT_NEG | 输出电容/负载电压 |
| VGS1 | G1 | VS_NEG（Q1源极） | Q1实际栅源电压 |
| VGS2 | G2 | SW_L（Q2源极） | Q2实际栅源电压 |
| VGS3 | G3 | VB_NEG（Q3源极） | Q3实际栅源电压 |
| iL | 串接测量或夹住电感单根引线 | 正方向 SW_L → L1 → IL_IN → 电流采样 → IL_OUT | 电感电流 |
| iB | 电池端正极单根导线 | 箭头 电源/电池VB+ → 板VB_POS | 放电为正，充电为负 |
| io | 输出正极单根导线 | 箭头 板OUT_POS → 电子负载+ | 输出电流 |

注意：PDF标题写 J1“1:+ 2:-”，但所见连接与PCB图把 J1 pad1 标 VS_NEG、pad2 标 VS_POS，存在标注冲突。接线必须按网络、实物连通关系和电容极性核对，不能只按标题或接线端左右。

电感取样跨板连接 J4 的 IL_IN/IL_OUT 必须形成完整串联电流路径；不接采样板时需有经确认的替代连接，不能留下开路或绕过保护测量。

### 3.2 三路驱动供电

板载 Si8220：J7(1=DRV1_15V，2=VS_NEG)、J8(1=DRV2_15V，2=SW_L)、J9(1=DRV3_15V，2=VB_NEG)。三组输出彼此隔离，负端不能互连。控制侧 CTRL_5V/GND 和 FPGA 共参考，不能额外跨接三个输出地。

J10：1/2/3为PWM_Q1/Q2/Q3，4为CTRL_5V，5/6为控制地。仅用板载或外接驱动其中一条路径，不并接两个驱动输出。

### 3.3 各模式设备接法

| 模式 | Vs端 | VB端 | Vo端 | 能量流向 |
|---|---|---|---|---|
| Vs→Vo | 源 | 不参与，按实际拓扑确认断开/隔离方案 | 负载 | Vs → Vo |
| VB→Vo | 不参与，按实际拓扑确认断开/隔离方案 | 源 | 负载 | VB → Vo |
| Vs→VB | 源 | 吸收通道/负载 | 不参与但仍监测其电容电压 | Vs → VB |
| SIDO | 源 | 吸收通道/负载 | 负载 | Vs → VB及Vo |
| DISO | 源 | 源 | 负载 | Vs及VB → Vo |

“不参与”不是将电源设0V或关输出的同义词；需依据实板二极管及寄生路径确认未用端口如何隔离。未用电容仍可能带电。

跨充放电模式切换时，VB端应由已配置好的可双向供/吸收功率设备保持连接。普通单向72V隔离电源不能默认吸收功率。SIDO需同时具备VB、Vo两个负载通道，且两路之间隔离关系满足本拓扑；不能把共负极双通道负载强接到不同负端。

第一轮换接设备一律 STOP、切功率电源、放电确认后操作；热切换试验必须保持设备接线不变，禁止运行中换端子。

## 4. 示波器探头怎么接

### 4.1 共用规则

- 三路 VGS 和端口电压均按差分测量安排：差分探头“+”接表中正端，“−”接表中负端。差分负端不是台式示波器的接地鳄鱼夹。
- 探头差模量程、共模电压、瞬态额定值均覆盖被测点；测VGS虽然只有约15V，其共模可能是功率节点电压。先接示波器端、确认衰减，再在断电放电状态接板端。
- 普通台式示波器通道地一般互连并接保护地。不能把三个地夹分别夹到VS_NEG、SW_L、VB_NEG；不能拆示波器保护地，也不能以给示波器加隔离变压器代替差分探头。
- 逻辑PWM/ADC传感器低压输出可用普通探头，但所有地夹仅接控制侧GND，仍核对USB/JTAG及仪器接地关系。
- 电流探头夹单根导线，不夹正负线整束；先消磁、调零，记录箭头。传感器输出测量须记录偏置/比例/带宽，不能直接把2.5V偏置当电流。
- 新增硬件 EVENT 标记应与模式/负载事件同次触发；串口回显的到达时间不是实际切换时刻。

### 4.2 四通道示波器分组（通道更多时可合并）

| 测量组 | CH1 | CH2 | CH3 | CH4 | 用途 |
|---|---|---|---|---|---|
| G：驱动与周期 | VGS1 | VGS2 | VGS3 | iL | 门极组合、阶段边界、电感斜率；Q3不参与也保存关闭证据 |
| O：Vo模式稳态/扰动 | Vo | iL | iB或io | EVENT或受控PWM逻辑 | VsVo/VBVo/DISO/SIDO输出响应 |
| B：电池模式 | VB | iL | iB | EVENT或受控PWM逻辑 | Vs→VB及充放电方向 |
| S：双输出/切换 | Vo | VB | iL | iB | SIDO及跨模式功率流；用外触发EVENT，或增加一次EVENT捕获 |
| I：输入扰动 | 受控端电压 | iL | 实际扰动输入Vs或VB | EVENT/另一路端口电流 | 输入扰动的实际幅度与响应 |
| A：采样时序 | CONVST逻辑 | BUSY逻辑 | PWM逻辑 | EVENT/计算完成标记 | ADC周期、相位、计算完成到PWM更新关系，均以控制地为参考 |

G组全部电压通道用差分探头。O/B/S/I中功率电压用差分，电流用电流探头。A组控制逻辑才使用控制侧共地普通探头。没有外触发时，S组分两次同工况采集，明确两次不是同一次事件，不能拼成同步证据。

VDS应力另做每管一组：差分+接漏极、−接源极，配VGS、iL，重点看关断尖峰；按器件实际D/S核对，不按封装外观猜。电感电压可差分+接SW_L、−接IL_IN（不把电流分流器压降包含进去）。

## 5. 五模式门极目标和开环设置

以下为物理三开关的待验收时序目标；程序必须先用仿真和无功率驱动测试核实。T=10 µs，局部脉宽至少保存两个完整周期，不用整页挤几十周期替代阶段分析。

| 模式 | Q1/S1 | Q2/S2 | Q3/S3 | 需核对 |
|---|---|---|---|---|
| Vs→Vo | PWM d | 与S1同相同占空比 | 关 | 110→000，两管同步，电感充放电 |
| VB→Vo | 关 | 常开（正常运行时） | PWM d | 011→010，驱动须支持S2常开 |
| Vs→VB | 常开（正常运行时） | PWM d | 关 | 110→100，测量VB和充电方向 |
| SIDO | PWM d1 | 同周期起点PWM d2 | 关 | d2<d1；110→100→000 |
| DISO | 前半周期PWM d1 | 前半随S1，后半保持开 | 后半周期PWM d2 | 110→000→011→010；S2不是只有前半脉冲 |

DISO在本方案采用半周期分配α=0.5，d1/d2均按整个T定义，0<d1<0.5、0<d2<0.5。预期 S1=[0,d1T)，S2=[0,d1T)∪[T/2,T)，S3=[T/2,T/2+d2T)。当前台架AUX=[T/2,T)，需经拓扑核定后由FPGA内部合入S2，不能直接用导线短接两个FPGA输出。原SLX的其它拓扑开关需逐项说明是测试夹具还是实物必需元件；若无法映射，本项功率试验不执行。

理想CCM标称值仅用于解释和核对趋势，不是首次上电指令：

- Vs→Vo：|Vo|=Vs·d/(1−d)，48→120 V理想d=0.714286。
- VB→Vo：Vo=VB/(1−d)，72→120 V理想d=0.4。
- Vs→VB：VB=Vs/(1−d)，48→72 V理想d=1/3。
- SIDO：固定d1=0.75时，理想伏秒平衡为Vo(1−d1)=Vs·d1−VB(d1−d2)，得到d2=2/3；输出负载及VB吸收条件还决定功率分配。
- DISO α=0.5时：d1=0.5·120/(48+120)=0.357143，d2=0.5·(1−72/120)=0.2；S2整周期占比约0.857143，不能把它误记成0.357143。

低压轻载可能DCM，损耗/死区/源限流会改变增益，不能仅凭理想电压不符认定程序错误。SIDO/DISO多占空比须满足区间顺序，不能任意独立扫满0～100%。NN/仿真约束不自动构成实物的安全上限。

## 7. 逐步执行：先ADC，再五模式开环

### E0：ADC/标定（不接功率）

1. adc_uart现成bit下载，确认启动文字、约2.1s后S=1/E=0/N增长；串口115200/8N1。
2. 四路分别接0V、2.5V、约3.3V，以万用表实测为准；默认ADC±10V，3.3V原码约10813。记录每路均值、波动和误差，不用悬空通道验收。
3. 接采样板：两路电流先零点，再已知正电流与可实现的反向电流；两路电压至少零点及两个已知点。拟合增益/偏置，保留原始记录。
4. 名义比例 I=(Vadc−2.5)/0.082，V=(Vadc−2.5)×120.5；标定后替换，不能把名义比例当实测精度。
5. A组/ILA看10µs采样周期、有效帧、错帧/故障，确认同帧四路。串口仅显示快照，不能单独证明全速对齐。
6. 采样映射：通常CH1=iL、CH2=Vo、CH3=io、CH4=VB；Vs→VB网络需要VB及电池支路电流，必须显式切换采样接线/复用方案和配置。当前两电流定义为iL/io，不能直接声称也测得iB；需要临时改测点并标记或增加测量路径。整个运行中禁止靠软件名字假装换了物理测点。

### E1：串口及驱动（不接功率）

1. 新OPEN bit先验证命令和错误处理；上电STOP、占空比0，配置完成不会自动启动。
2. J7/J8/J9隔离供电核对；PWM关闭下测三路VGS。
3. 各模式G组波形，核对第5节全部状态、100kHz及受控脉宽；DISO特别核S2后半周。
4. RUN/STOP、非法命令、非法占空比、串口中断、按键停止、故障锁存逐个测。停止/故障应执行已经审核的输出动作，不能只看串口文字。
5. 测数字切换边界无毛刺、参数原子更新、超时退出。此时可测全部请求，不代表带电切换获准。

### E2：五模式逐个开环功率试验

执行顺序：Vs→Vo → VB→Vo → Vs→VB → SIDO → DISO。每个模式都重新填写工况卡。

1. 断电、放电，按端口表连接，核对电容极性、iL测量闭合路径、未用端口、探头及负载。设备吸收能力和电源反灌防护到位。
2. 控制先保持STOP；驱动/控制电源就绪，反馈读数可信。功率源先设低压、限流，按该模式规定的负载使能/预充顺序供电；CV电池模拟和CR输出负载不采用同一套未经核对的启动顺序。
3. 小占空比/受控斜坡启动并单次捕获启动段。SIDO/DISO使用审核的成组起始参数，不任意改变一个脉冲导致区间失序。
4. 停在低压检查输入电流、端口极性、电感峰值、门极；通过后只改变一个变量逐点升压/加负载。每点保存实测输入、负载及d，直到工况卡目标；不开环盲追120V。
5. 每模式记录至少一个低压点、一个中间点、目标点；第一轮以完成运行机制验证为主，额定点仅在器件应力和保护允许时执行。
6. 稳态G组、O或B组，SIDO另S组；按工况卡停机，捕获停机过程，再关闭功率源并确认放电。

立即停止条件：达到工况卡任一限值、输入持续顶限流、输出失控、供电反灌超规格、驱动欠压/故障、ADC错误/饱和、电流斜率异常或明显热异常。电源限流不能替代逐周期过流保护。

## 8. 开环模式切换：先接线不变，再请求切换

### 8.1 覆盖范围和执行次序

| ID | 路径 | 要证明什么 | 前置条件 |
|---|---|---|---|
| SW-O1 | VsVo ↔ SIDO | 单输出与双输出转换，VB由不参与到吸收 | VB可吸收；Vo负载持续接入；不参与端口已核对 |
| SW-O2 | VsVo ↔ DISO | 单源与双源转换，VB供能加入/退出 | VB源与防反灌能力核定，DISO物理门极完成 |
| SW-O3 | SIDO ↔ DISO | VB充电/放电方向反转 | VB双向设备、iB测量和换流路径完成；最后做 |

三个SISO模式间的转换另列扩展项：涉及不同受控端口/采样配置，第一版不默认任意两模式都能热切换。五模式均可在STOP后选择；仅白名单内的边允许带电切换。老师如需其它边，先补该边的功率路径/采样/续流分析。

### 8.2 每条路径怎么测

1. 两个端点模式分别已在相同设备接线下稳定运行；配置源/吸收设备，运行中不改线。
2. 在较低能量工况，事先装载目标占空比组合、边界限值及切换策略。开环切换不要求输出完全恒定，观察有限且可解释的偏差。
3. 示波器S组，EVENT外触发，单次捕获；记录t0前后的Vo、VB、iL、iB。另用G组记录实际VGS时序，每次重复标记独立编号。
4. 串口SWITCH请求仅排队，FPGA验证条件后在既定PWM边界执行；EVENT标出实际提交时刻。不能用PC发送时间替代t0。
5. 顺向、反向分别至少3次。低能量全部通过后逐级提高工况，每次核对输入、负载和初态。
6. 验收：端口功率方向符合目标；未发生失控、超限或故障；峰值、最低值、切换完成时间均有原始数据。热切换策略未完成前只进行E1数字切换和STOP换模式，不把停机重启写成无缝切换。

必须补齐：现有SLX额外开关与真实Q1/Q2/Q3/二极管的对应、带电电感续流路径、模式驻留/资格时间、故障退出。不能把“一周期全低”等同于保证安全或无扰切换。

## 9. 闭环：五模式全做，切换选择性做

### 9.1 每模式 PI/NN 共同测试表

| ID | 试验 | 保存内容 |
|---|---|---|
| CL-1 | 启动至目标，再正常停止 | 受控电压、iL、实际PWM/阶段标记，启动和停止全局图、接管局部图 |
| CL-2 | 稳态 | 受控电压均值/纹波、iL均值/RMS/峰值/峰峰值、io/iB、G组至少2周期 |
| CL-3 | 轻→重负载、重→轻负载 | 实际电流或负载触发信号、受控电压、iL，完整扰动及局部恢复 |
| CL-4 | 输入电压下降/恢复（条件允许） | 实际输入电压、受控电压、iL、触发；斜率和幅度与PI/NN保持一致 |
| CL-5 | 停机与保护验证 | 先无功率注入故障；功率侧仅受控验证，记录故障到门极动作和电流续流 |

先完成PI，再同模式NN。NN固定权重推理，启动器将状态带入已验证工作域后切入；固定72/120V网络不任意改参考做参考阶跃。PI与NN比较须使用相同功率板、L/Co、端口条件、负载、电源变化、PWM频率和测量带宽，且说明启动器不同之处。

各模式补充：Vs→VB以VB/iB为主；SIDO同时报告Vo、VB、iB，明确仅控制Vo的网络不等于双电压独立调节；DISO报告两输入功率及iB正方向，区分一个输出电压目标与两个占空比，PI的功率分配/第二自由度策略必须明确。

负载基线：正式仿真Vo负载48↔96Ω，对应120V时300↔150W；Vs→VB为20↔40Ω，对应72V时259.2↔129.6W。这是完整目标工况，不是首轮功率。先较轻CR负载逐级验证，再决定是否执行该功率；电子负载用CR对齐仿真电阻，若用CC须另行标注，不能称相同负载模型。

每种扰动、每个方向至少3次，保存所有重复；PI/NN的初始稳态、负载事件和源限流一致。不得只选最好的一次；汇报均值及范围，异常单列原因。

### 9.2 选择性闭环切换

第一候选 SW-C1：VsVo ↔ SIDO，突出三端口增加/退出吸收端口的能力。必须先SW-O1通过，VB吸收条件成立。若该设备/路径不便，候选 SW-C2：VsVo ↔ DISO，须先SW-O2通过及DISO物理映射完成。最终根据开环实测与老师选定其中一组为主；SIDO↔DISO留后续，不作为首轮闭环进度前提。

同一条选定路径在PI、NN各自固件内切换，使用同条件，不在一次记录中把控制器也换掉。完成进入/退出两方向、各3次，S组和G组证据齐全。采样定义、控制器状态、目标占空比、参考和限幅在切换中要一致处理；新模式积分器/启动器预置方案须明确，不能仅换mode编号。

## 10. 每次保存哪些图、数据及指标

### 10.1 必存图

| 图号后缀 | 内容 | 横轴/触发建议 |
|---|---|---|
| START | 从启动前到稳定的全局电压/电流 | RUN实际生效标记，预触发20%～30%；覆盖完整启动器时间 |
| CYCLE | VGS组合与iL，标出各开关模态 | 100kHz下20～30µs窗口，至少2完整周期；门极边沿触发 |
| STEADY | 端口电压/电流稳态及必要纹波放大 | 连续至少100周期的原始记录；另保存2～5周期局部图 |
| LOAD/INPUT | 扰动前稳态、全过程、恢复后稳态 | 实际负载电流边沿或输入电压/仪器触发，保留预触发 |
| SWITCH | 切换全局Vo/VB/iL/iB，以及门极边界局部图 | 实际EVENT触发；局部至少覆盖t0前后2周期 |
| STOP/FAULT | 停机/受控故障和剩余电流行为 | 实际请求/故障标记触发 |
| VDS | 每管关断应力局部（初调及提高功率后） | VDS边沿/脉宽触发，与VGS及iL对照 |

控制瞬态记录先选足够长窗口（现有启动流程可到200ms，不能只抓几毫秒），再依据实测恢复时间调整。周期图建议≥100MSa/s作初始设置，边沿测量需根据实际上升时间/探头带宽提高；不是凭采样率数字保证尖峰精度。长记录必须检查实际采样率及存储深度，禁止用抽点图测尖峰。纹波测量可另做AC耦合/带宽限制，但峰值/直流图必须保留DC测量且记录带宽，不能只存AC耦合图。

每图保存：示波器原生波形、带时间列的CSV、原始截图、通道与探头设置；串口日志和本次工况卡一同保存。截图不是唯一原始数据，后续论文重绘不得替换/合成事件。网口不是必需，示波器CSV可供MATLAB后处理；内部NN输入/命令对齐问题再启用现有网口记录。

### 10.2 指标定义

- 稳态窗口：选事件前、且已经收敛的连续Wpre；事件后选恢复后的连续Wpost，记录精确起止时刻。窗口取整周期且至少100周期，未收敛不得宣称稳态。不同算法同一比较使用相同长度和选取规则。
- 电压均值、误差：(mean(V)−Vref)/Vref×100%；峰峰值=max−min，注明滤波/带宽。
- iL有效值：sqrt(mean(iL²))；交流纹波RMS另算sqrt(mean((iL−mean(iL))²))，两者不混用；峰值给max与min，必要时另报max(abs(iL))。
- 扰动电压偏差：相对事件前稳态均值的最大正偏差和最大负偏差；另报相对参考的最大偏差，不能混用。
- 恢复时间：从实际事件t0起，第一次进入并持续留在声明误差带的时刻减t0。建议先报告±2%参考带，持续时间至少1ms/100周期；如稳态纹波本身超过该带，应如实记未满足，不能事后放宽而不说明。
- 切换时间：请求接收到目标模式实际生效为调度延迟；t0到目标能量流及电压满足声明条件为系统切换/恢复时间，分开报告。
- 端口功率：同步电压电流取mean(v·i)，iB>0为VB向板供电，iB<0为板向VB充电。不同时间的两个表读数乘积只作近似，不写成精密效率。
- 采用负载48Ω/96Ω、72V端负载等条件必须写实际值和扰动时刻；PC推理时间不代替FPGA采样到PWM延迟。

## 11. 串口命令规格（待实现，旧bit不支持）

115200、8N1、ASCII，一行一命令，CRLF。波特率用于人工操作和慢速遥测，不承担100kHz闭环，不把PC串口延迟放进控制回路。

| 命令示例 | 行为 |
|---|---|
| `STATUS?` / `HELP` / `VERSION?` | 状态、命令表、OPEN/PI/NN固件标识与基线/标定版本 |
| `MODE VSVO` / `MODE VBVO` / `MODE VSVB` / `MODE SIDO` / `MODE DISO` | 仅STOP时选工作模式；不启动 |
| `DUTY 0.1000` | OPEN单占空比模式的暂存参数，仅STOP配置；不代表推荐首次值 |
| `DUTY 0.7500 0.6667` | OPEN双参数模式的暂存值，按第5节定义校验；示例仅示意，不建议直接上电 |
| `CONFIG?` | 回读mode、参数、范围、采样映射、切换白名单 |
| `RUN` | 所有条件满足后执行已定义启动流程；若ADC/硬件保护不满足则拒绝 |
| `STOP` | 高优先级停止请求，执行经核定的停机策略；实测停止响应 |
| `TARGET SIDO 0.7500 0.6667` | OPEN运行切换前暂存目标模式及参数，校验后仍不执行 |
| `SWITCH SIDO` | 请求白名单切换，OPEN需匹配目标参数；PI/NN采用对应模式配置 |
| `CLEAR` | 仅STOP且故障源消失时清锁存；不得自动RUN |
| `TELEM ON` / `TELEM OFF` | 开关慢速遥测，不影响闭环与保护 |

OPEN/PI/NN为编译目标，不通过MODE选择算法；PI/NN不接受DUTY覆盖计算，不开放任意参考值。未来确需参考阶跃时先扩展验证域。

实现要求：

1. 状态机 STOP → STARTING → RUNNING → TRANSITION → RUNNING；FAULT锁存。停止和故障可打断配置/启动/切换；故障清除只回STOP。
2. 单条命令完整解析后一次提交；超长、超时、错误数值、NaN、非法模式/范围返回ERR，不改变有效参数。半条命令不得改变PWM。
3. `OK QUEUED`与`APPLIED`分开，APPLIED携带mode、帧号、PWM周期计数/时戳。事件脚与实际提交同步，事件脚另选空闲引脚，不能复用尚用于AUX的Y16。
4. PWM参数在共同周期边界原子更新，闭环计算仍由100kHz时基运行；不得把UART接收字节直接连到占空比寄存器。
5. 本地按键仅停止/复位，不再轮换模式；硬件过流直接走保护链。串口STOP不是急停装置。ADC故障、驱动失电等处理依据功率级审核确定。
6. 断线策略显式记录：上电默认通信未授权；RUN前授权。运行中通信丢失不产生任何切换命令。是否在超时后受控停机需配置并实测，不能“无限期满功率保持”作为未声明默认。重连不自动RUN。
7. 固定RX输入须先核对P3剩余引脚与ACM7606、三PWM、AUX/EVENT无冲突，再加XDC。现有TX为P3第31脚/V15，CH340 RXD接它；CH340 TXD接新增FPGA RX，确定前不得随意接。
8. 发送状态包含mode、algorithm、state、fault、ADC帧号、受控端口、有效占空比、原始码/物理量；遥测拥塞不得阻塞保护与计算。

串口控制验收用例：正常命令、重复RUN/STOP、连发、丢半行、错误字符/模式/数值、溢出、掉线重连、运行时非法MODE/DUTY、运行时合法白名单SWITCH、故障时RUN/CLEAR、切换中STOP、复位重上电。全部先数字仿真和无功率板测通过再接功率。

## 12. 执行入口与完成判据

下一次现场先执行E0 ADC；串口OPEN程序改造与仿真完成后执行E1，再逐个E2。开环单模式全通过后做SW-O1/O2/O3，按硬件条件逐级解锁；同时完成PI各模式和NN部署一致性，再执行CL-1～5。闭环切换从开环已通过的边中选一组。

计划覆盖五模式，不用“先做一个”替代老师要求；但某项未满足源/吸收条件、物理门极映射或换流策略时，状态记“未执行及原因”，不得拿数字仿真冒充功率实测。每项合格必须同时有工况卡、原始记录、指标和结论。
