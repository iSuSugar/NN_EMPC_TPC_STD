# 参考论文实现方法与我们的最简路线

更新：2026-11-03。本文只研究方法、修正路线；没有改 FPGA RTL、下载硬件、重新辨识或训练。

**结论：采用“电脑离线生成控制器，FPGA在线采样并计算占空比”的路线。先打通一个模式的真实闭环，不把实物数据辨识、DDR记录和网络传输作为闭环的前置条件。**

## 2. 他实际怎样做：六步就能串起来

### 第一步：由电路得到控制模型

I4SL-boost 是四电感、一个有源开关的升压电路。开通时四电感并联充电；关断时串联向输出供能。式(1)～(6)给出模态方程，假设四电感相同、支路均流后，用一个代表支路电流和输出电压构成二阶控制模型。

这里的电流是**一个电感支路电流**，不是四支路总和。论文也明确说明，降阶模型不能描述全部支路失衡。

以理想 CCM 为条件，伏秒平衡给出式(7)：

\[
D V_{in}+(1-D)\frac{V_{in}-V_o}{4}=0,
\qquad \frac{V_o}{V_{in}}=\frac{1+3D}{1-D}.
\]

因此它的20V→100V名义工况对应 D=0.5。这是该拓扑的公式，不能拿来算我们的三端口占空比。

第4页式(8)采用两个状态、一个占空比输入的离散线性预测形式；图5和式(9)另展示状态预测误差。**这与后面拟合最优占空比的网络不是同一个任务。**

### 第二步：在电脑上生成局部 EMPC 教师

目标是输出电压跟踪参考，式(10)对预测电压误差加权；式(11)加入电流、电压、占空比约束。第7页报告的配置为：

- 采样周期10µs，开关频率100kHz，预测时域50步，电压误差权重 q=10。
- 约束：0≤D≤1，0≤iL≤30A，0≤Vo≤150V。
- 输入 move-blocking：前三个预测占空比动作相同。**不能把这句话直接写成“控制时域就是3步”。**
- 按不同输入电压、负载建立局部预测模型和局部 EMPC。

离线求解多参数二次规划，得到分区和每区仿射控制律。式(12)写为：

\[
D_{opt}=A_r\begin{bmatrix}i_L\\V_o\end{bmatrix}+B_r.
\]

这里的 Ar、Br 是**控制律系数**；它们与预测模型的 A、B 作用不同。第5页给出的一个输入电压20V案例有628个区域。

### 第三步：跑 EMPC 闭环仿真，记录训练样本

第6～7页给出的四个工况：

| 工况 | Vin | 负载R | 保留样本 |
| --- | --- | --- | --- |
| 1 | 15V | 50Ω | 200组 |
| 2 | 20V | 50Ω | 200组 |
| 3 | 25V | 50Ω | 200组 |
| 4 | 20V | 100Ω | 200组 |

每组同步记录：

\[
\underbrace{[i_L(k),V_o(k),V_{ref}(k)]}_{网络输入}
\quad\longrightarrow\quad
\underbrace{D_{opt}(k)}_{相应局部EMPC的第一步最优动作}.
\]

论文用过 a+1|a 等记号；复现时要按实际采样/施加时序对齐，不能只按表格行号配对。

合计800组，沿闭环启动轨迹等时间间隔取样，并非整个可行域均匀铺点。打乱后按70%/15%/15%分训练、验证、测试集。负载阶跃和输入电压阶跃轨迹没有直接纳入这批训练数据，而用于后续闭环验证。

**它没有要求先搭好实物、手动扫描占空比，再把扫描占空比当“最优标签”。** 手动给定 D 与 EMPC 求出的 Dopt 不是一回事。

### 第四步：在 MATLAB 训练占空比网络

论文采用 **3→8→1**：输入 iL、Vo、Vref；单隐藏层8个 tansig 神经元；输出线性。

\[
\tilde{x}_j=2\frac{x_j-x_{j,min}}{x_{j,max}-x_{j,min}}-1,
\quad h=\tanh(W_1\tilde{x}+b_1),
\quad \tilde D=W_2h+b_2.
\]

输入缩放到[-1,1]，输出做反归一化并限幅。训练目标是占空比误差，式(19)：

\[
E_{off}=(D_{opt}-D_{NN})^2.
\]

报告的训练设置：最多1000轮、学习率0.001、性能目标10⁻⁸。实际最佳验证性能为第365轮7.4465×10⁻⁵，**目标值不等于实际达到的误差**。权重/偏置列在式(20)。

训练完成后将权重、偏置、归一化常数带到 FPGA，在线只前向计算，不在线训练，也不每周期重新求 MPC。

### 第五步：FPGA在线按一个固定周期执行

论文第8～9页：Artix-7 xc7a35tfgg484-2，系统时钟50MHz，网络数据通路采用400kHz控制时钟；三段寄存结构分别做归一化、隐藏层、输出层及缩放/限幅，层内并行计算。

| 论文报告的量 | 实现 |
| --- | --- |
| 小数缩放 | 以2¹⁰为基准 |
| 归一化输入 | 17位有符号 |
| 隐藏层输出 | 20位有符号 |
| 乘加中间量 | 35位有符号 |
| 最终占空比字 | 11位有符号 |
| 网络延迟 | 3×2.5µs=7.5µs |
| 控制采样周期 | 10µs |

计算所得占空比锁存，交给后续 PWM 更新。**7.5µs是网络推理延迟；文中没有完整列出ADC转换/读取、采样位置到PWM生效的逐段时序，不能据此宣称整条链路只需7.5µs。**

### 第六步：做仿真与实物对比

仿真比较 PI、传统 EMPC、NN-EMPC，验证 NN 是否保留教师的主要动态响应；目标不是证明学生网络必然优于教师。

实物比较 PI 与 NN-EMPC，使用同一200W样机、100V参考、100kHz开关频率、相同采样和扰动条件。主要实验是稳态、50Ω↔100Ω负载变化、20↔25V及20↔15V输入变化。第10～11页的实测主要以示波器波形呈现。

表VI的332KB→1.5KB是四个局部 EMPC 合计控制数据与统一网络参数/归一化常数的比较，不是整块 FPGA 的总存储；传统 EMPC仅综合。表III的平均计算时间是MATLAB/Simulink时间，不能拿来当 FPGA 实时延迟。

## 3. 我们可以直接借鉴什么，需要保留哪些区别

**控制方法相近，不能理解成“改个电路图，其他完全不变”。**

| 项目 | 参考论文 | 我们当前先做的Vs→Vo |
| --- | --- | --- |
| 方法 | EMPC生成标签，NN拟合，FPGA执行 | 可以采用同样分工，优先用已训练网络 |
| 网络 | 3→8→1，tansig/线性 | 4→16→8→1，ReLU/ReLU/线性，225参数 |
| 输入 | iL、Vo、Vref | iL、Vo、Io、Vref |
| 实际ADC | 反馈测iL、Vo；Vref为内部命令 | 已规划4路：iL、Vo、Io、另一端口电压；Vref仍是内部命令 |
| 调制 | 单有源开关，单D | 三路门极按模式映射；SIDO/DISO还需对应控制量、时序与约束 |
| 跨工况 | 同一拓扑四个工况训练一个网络 | 不能由此推出五种功率模式共用当前一个网络 |
| 数据取得 | 仿真生成教师标签；实物验证 | 先部署现有网络，实物数据用来验证；必要时再更新模型/训练 |

当前保存的Vs→Vo网络已核对：第四维 Vref 的归一化增益为0，对应训练时固定120V，不能宣称任意改参考值都有效；CH4端口电压也不能直接填入这第四维。

## 4. 我们的软件和硬件各自负责什么

MATLAB：电路模型/必要的模型辨识 → MPC/EMPC教师 → 生成训练样本 → 网络训练与闭环仿真 → 导出固定参数。

FPGA：ADC同步采样 → 原始码转换为物理量 → 按训练参数归一化 → PI或NN计算 → 限幅/有效性检查 → 在约定周期更新PWM。

用你熟悉的C表达**执行关系**如下；这不是可直接用于功率板的代码，RTL中各模块还要用valid握手和时序配合：

```c
if (adc_frame_valid) {
    feedback = calibrate(adc_frame);       // 同一帧iL、Vo、Io等
    if (feedback_invalid(feedback)) {
        fault_stop();
    } else {
        duty = nn_forward(feedback.iL, feedback.Vo,
                          feedback.Io, Vref_command);
        pwm_shadow = limit_duty(duty);    // 等约定边界生效
    }
}
if (pwm_period_boundary && new_command_valid)
    pwm_active = pwm_shadow;
```

采样超时、启动、过流/过压等处理仍是必要控制功能。占空比限幅只能限制D，不能自动保证电流、电压永远满足EMPC约束。

## 5. 当前主线收敛为三类程序

| 程序 | 用途 | 当前先验证什么 |
| --- | --- | --- |
| 开环验证 | 固定/受限占空比PWM＋ADC观察与必要记录 | PWM正确；四通道量程、极性、零点/比例；采样同步 |
| PI闭环 | ADC→标定→PI→限幅→PWM | 先在Vs→Vo上实现可控启动和稳压；增益针对我们的电路整定 |
| NN-EMPC闭环 | ADC→标定→归一化→已有NN→限幅→PWM | 与MATLAB同输入对拍；完整链路时序；同工况稳压与扰动实验 |

PI和NN版本分别烧录测试，共用已验证ADC/PWM等模块。开环用于硬件验证与必要记录，不是强制重新造一套训练集。PI闭环之后是NN闭环，不称“PI开环”。

下一步顺序：**先测现有ADC工程 → 测PWM/ADC同步 → 在现有模块上组装Vs→Vo PI闭环 → 组装Vs→Vo NN闭环 → 再逐模式扩展与切换。**

原网口N1已经完成软件验证，保留作记录通道的可选测试，不删。暂停自动推进N2/N3、DDR和补传系统；需要长时全量记录时，再按实际采样率、长度、导出速度选缓存。BRAM还是DDR是容量选择，不是采样对齐的定义。

## 6. 采集导出保持简单，但每行确实对齐

你说“采集好直接导出”是正确的使用目标。FPGA内部负责让同一条记录有明确含义，MATLAB读到后不用猜。

最小记录约定：**采样序号、采样时刻、同一帧4路原始码、采样时实际生效的占空比/模式**。计算结果若下一周期才生效，要能明确对应哪次采样与哪次PWM更新。物理换算比例和单位随实验配置保存。

这些数据可以用于波形分析、模型核对，必要时做辨识。**开环指定的占空比本身不是最优监督标签**；如要重新训练EMPC近似器，教师标签仍来自目标MPC/EMPC。

控制器运行不等待PC接收数据。串口先看数值；示波器看开关/动态波形；需要全量数字数据时接已有网口路径。无论采用哪条导出路径，都检查记录序号和完整性，丢失要明确报告；这不要求现在先搭一个复杂通信平台。

## 7. 认真复现时，论文中仍需自行补齐的实现细节

这些是“正文未充分给出”，不据此判定作者实现有错，也不因此扩展当前FPGA任务。

1. **预测模型如何得到固定A、B。** 模态平均模型含D与状态的乘积，直接Euler离散化并不自动成为固定系数、无常数项的式(8)。正文提到电路参数推导，又展示随机初始系数的误差，但没有完整给出每工况最终A/B、线性化工作点/偏差坐标或辨识数据。我们的讲解必须以自己原工程实际实现为准。

   在其理想均流模型下，平均方程可由式(3)、(6)推得：

   \[
   \dot i_L=\frac{(1+3D)V_{in}-(1-D)V_o}{4L},
   \qquad \dot V_o=\frac{(1-D)i_L}{C}-\frac{V_o}{RC}.
   \]

   两式含 DVo、DiL；若做工作点小信号线性化，需明确使用状态/输入偏差。此处是我们的推导说明，不是论文公开了这些离散矩阵。

2. **tansig如何在硬件实现。** 正文给出数学激活函数和并行结构，没有公开足以直接重建的查表/近似、权重定点格式、溢出/舍入细节。我们已训练的是ReLU网络，保留自己的激活与验证结果，不为模仿论文改成tansig。
3. **完整采样到PWM的延迟。** 推理时间达标只是其中一段。我们的ADC读取、换算、NN和PWM提交须合计验证，按真实生效周期建模，不拿现有NN核425拍的4.25µs代替全链路时间。
4. **训练覆盖和约束。** 800组来自指定轨迹，随机拆分可能包含相邻点，不能证明任意状态/工况泛化。我们保留独立扰动工况与约束检查，不能照搬“800组就够”或“网络天然保证约束”。
